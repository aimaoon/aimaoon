# asset pipeline

asset_pipeline_mode: D

## 決定（第0-5節）

ユーザーの選択により **モードD：画像生成機能を持つ別環境で原画を作り、このセッションへ配置する** で確定。

| 担当 | 作業 |
|---|---|
| ユーザー（別環境） | 基準キャラクター1枚と専用ポーズ原画の生成・配置 |
| Claude（本セッション） | 設計・マスク抽出・部位分離・リグ・中割り・APNG化・容量最適化・全検査・プレビュー生成・提出物作成 |

Claude Code には組み込み画像生成ツールが存在しないため、Claude 側は原画を描き起こさない。
コードで円・楕円・多角形を組み合わせてキャラクターを作ることは第0-5節で明示的に禁止されている。

## 各モードの本環境での可否（判断の記録）

| モード | 内容 | 本環境での可否 | 採否 |
|---|---|---|---|
| A：ユーザー提供原画 | 既に手元にある原画を提供 | 可能（既定モード） | 不採用（原画未所持） |
| B：画像生成API | エンドポイントとキーを提供し Claude が呼び出す | egress制限あり。`creator.line.me` は遮断済みで、APIホストへの到達性は未確認 | 不採用 |
| C：ベクター原画 | 承認済みSVGをパラメトリック変形 | SVG提供時のみ可能 | 不採用 |
| D：別環境で生成 | 別環境で原画を作り配置 | 可能 | **採用** |

## 必要な原画（合計265枚）

`reports/asset-order.md` が発注書。`emoji-plan.json` と `style-lock.json` から生成しており、内容を二重管理しない。

| 種別 | 枚数 | 配置先 |
|---|---:|---|
| 基準キャラクター | 1 | `character-master.png` |
| 専用ポーズ原画 | 192 | `poses/NNN/P1-first.png` 〜 `P6-return.png`（01〜32） |
| 本体のみ版（採寸用） | 32 | `poses/NNN/P1-body.png`（01〜32） |
| 記号の状態原画 | 40 | `poses/NNN/S1-complete.png` 〜 `S5-scatter.png`（33〜40） |

2×2シートで生成した場合は `scripts/split_pose_sheet.py` で個別ファイルへ分割する。
空マスとマスまたぎを自動検査する。

## 受け入れ順序

1. `character-master.png` のみ先に受け取り、承認ゲートを通す（§6）。**承認前に他を量産しない。**
2. 承認後、`01-04` のプロトタイプ4個分（24枚＋本体のみ4枚）を受け取り、
   ポーズ承認ゲート（§8-3）と20フレームの販売品質プロトタイプ（§8）で方式を検証する。
3. 方式確定後、4個ずつのバッチで残りを受け取る（§0-6）。記号 `33-40` は独立バッチ。

## AI使用申告（§12 に転記する事実）

- キャラクターおよび記号の原画は、ユーザーが別環境の画像生成ツールで作成したものである（モードD）。
- Claude Code はアニメーション設計・部位分離・中割り・APNG生成・検査・提出物作成を担当し、原画の描画は行っていない。
- 実際に使用した生成ツール名は、原画受領時にユーザーから聴取して本欄へ追記する。**現時点では未確定。**

## 基準デザインの変更（2026-09-02）

ユーザーから案B「刺繍とフェルトの手芸カワウソ ステッチ」の10ポーズシートを受領し、
基準デザインを**案C「レトロソフビ ダイオウ」から案Bへ変更**した。

受領したシートは方向性の確認用として採用し、**原画としては不採用**とした。理由は実測に基づく:

| 不採用の理由 | 実測値 |
|---|---|
| 粒状テクスチャで容量仕様を満たせない | 20フレームAPNGで 1,179,874 bytes（上限 300,000 の3.9倍） |
| 透過がない | mode=RGB、透過画素0、背景はクリームの紙テクスチャ |
| 文字が焼き込まれている | タイトル・ラベル・説明文あり |
| 1枚に10体、寸法不一致 | 1536×1024（要求は720×720／1ポーズ） |
| 感情セットが40個テンプレートと不一致 | びっくり・どや・いたずら等 |

**フラット描画（10色ベタ塗り、粒子・繊維なし）での再生成**を発注書へ反映済み。
10色フラットの実測は 154,017 bytes で合格圏。詳細は `reports/art-style-feasibility.md`。
