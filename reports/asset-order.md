# 原画発注書（調達モードD：別環境で生成）

本ファイルは `python3 scripts/make_pose_order.py` の出力である。
emoji-plan.json / style-lock.json を唯一の入力とし、内容を二重管理しない。

## 役割分担

| 担当 | 作業 |
|---|---|
| **あなた（別環境）** | 下記の原画を生成し、指定パスへ配置する |
| Claude（本セッション） | マスク抽出・部位分離・リグ・中割り・APNG化・容量最適化・全検査・プレビュー生成・提出物作成 |

Claude はコードで円・楕円・多角形を組み合わせてキャラクターを描き起こさない（§0-5 の禁止事項）。
原画が届くまで、01〜32 の第1フレームもアニメーションも作れない。

## 必要枚数

| 種別 | 枚数 | 内訳 |
|---|---:|---|
| 基準キャラクター | 1 | `character-master.png` |
| 専用ポーズ原画 | 192 | 32個 × P1〜P6 の6ポーズ |
| 本体のみ版（採寸用） | 32 | 32個 × P1 から小物とエフェクトを除いたもの |
| 記号の状態原画 | 40 | 8個 × S1〜S5 の5状態 |
| **合計** | **265** | |

§8-1 は 01〜32 について各6枚を必須とし、4枚への省略を禁じている。`dedicated_pose_count` が6未満の項目があるとアニメーション工程へ進めない。

## 共通制作ルール（全枚数に適用）

- **解像度 720×720px**。最終180pxの4倍で描き、Claude 側が `Image.LANCZOS` で180pxへ縮小する（§9-5）。
- **背景は透過**、または均一なクロマキー。透過後に緑縁・白縁が出ないこと。
- **文字・ラベル・透かし・不要な影を入れない。**
- 全ポーズでキャラクター本体を**同じ見かけの大きさ・基準位置**にする。ポーズごとに拡大縮小して構図を整えない。
- ポーズはセル番号ではなく**共通ステージ座標**へ配置する。2×2シートで作る場合も、各マスの中でキャラクターを中央揃えし直さない（§9-5）。
- 全ポーズが**上下左右8px（720px換算で32px）の安全域**に収まること。最大動作でも見切れない。

### 2×2シートで生成する場合

1マス 720px の 2×2（全体 1440×1440px）で生成してよい。
各マスを均等にし、十分なガターを設け、何もマスをまたがせないこと。
配置後、Claude 側で `python3 scripts/split_pose_sheet.py <sheet.png> --number NNN --roles P1,P2,P3,P4` により個別ファイルへ分割する。

## 基準キャラクター `character-master.png`

- 720×720px、透過、正面向きの直立、無表情に近い基本状態
- 商品コンセプト: 昭和の怪獣ソフビが、日常会話のときだけ手のひらサイズになって返事をする。
- 造形: 頭でっかちの三角。頭頂から提灯の突起が 1 本立ち、下端は太く短い二本脚で接地する。背面に 3 枚板の尾ひれ
- 頭身: 全高 118px / 頭高 46px。頭が最も重い塊で、胴と脚を合わせて 72px
- 素材: マットな塩ビ（ソフビ）。成型物であることを、パーティングライン・可動ボール・ガス抜き穴という 3 つの痕跡で示す
- 線: #14171C / 180px 出力時に 3.0px 一定。部位・スケールによらず変えない。許容差は見かけ上 ±10%（2.7〜3.3px）
- 配色（この10色から出ない）:
  - `#14171C` line
  - `#1F5E52` body_base
  - `#2E8375` body_light
  - `#123F37` body_shadow
  - `#F2E4CE` belly
  - `#3D4650` joint_gray
  - `#FFFFFF` white
  - `#FF6A2B` spray_accent
  - `#7FE3D0` effect_mint
  - `#E2453A` warn_red
- 必ず入れる視覚的フック:
  - **頭頂の提灯（発光する誘引突起）** — 装飾ではなく頭部造形の一部。角度と光量は変わるが形は不変
  - **体の中心を走る成型のパーティングライン** — 頭頂から腹まで。左右対称の基準線を兼ねる
  - **肩・股の丸い可動ボール 4 箇所** — joint_gray の露出球。リグの支点そのもの
  - **頭から背への蛍光オレンジの吹き付け帯** — 2 段のベタ帯。怒り・体調不良では色が変わる
- 陰影は1段のみ。光源は左上45度。光沢・グラデーション・粒状テクスチャ・ぼかし影・半透明グローを使わない。

**この1枚が承認されるまで、他の原画を量産しないこと。** 以後この画像が唯一の同一性基準になる。

## 採寸用「本体のみ版」について

`poses/NNN/P1-body.png` として、P1 から**小物・エフェクト・提灯の発光リング**を取り除いた版を1枚。
§5 のサイズ統一は主役だけのマスクで測るため、これが無いと `reports/scale-audit.csv` が算出できない（小物込みの外接矩形で測ってはならない）。
提灯そのものは本体の一部として**残す**。除くのは発光リングとエフェクトパーツだけ。

## 記号 33〜40 について

キャラクターを描かず、`symbol_style_lock` に従う。
- 線色 `#14171C` / 線幅 3.0px / 角の丸み 4.0px
- 光学面積の目標 4800px²（±12.0%）、文字系は cap height 62px
- 各パーツに**ガス抜き穴を1つ**入れる（シリーズの署名）
- 8個を色違いにしない。完成記号の変形だけで済ませず、最低5状態を作る。
