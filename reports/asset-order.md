emoji-plan.json / style-lock.json を唯一の入力とし、内容を二重管理しない。

## 受領済みシートからの是正点（2026-09-02 受領の10ポーズシート）

方向性は採用する。ただし次はすべて直す必要がある。実測の根拠は `reports/art-style-feasibility.md`。

| 項目 | 受領物 | 直すこと |
|---|---|---|
| **質感** | 紙の粒子とフェルトの繊維あり（ユニーク色 14,911） | **フラット描画。ベタ塗りのみ。粒子・繊維・布目・にじみを一切描かない** |
| 容量 | 20フレームAPNGで 1,179,874 bytes（上限の3.9倍） | 10色フラットなら 154,017 bytes で成立する |
| 背景 | クリームの紙テクスチャ、透過なし | **完全な透過（RGBA）** |
| 文字 | タイトル・ラベル・説明文が焼き込み | **画像内に文字を一切入れない** |
| 構成 | 1枚に10体 | 1体ずつ、または2×2シート |
| 寸法 | 1536×1024 | **720×720px／1ポーズ** |
| 感情 | びっくり・どや・いたずら等 | 下記「個別指示」の40種に従う |

**16色へ量子化しただけでは 398,332 bytes で不合格だった。**容量を支配しているのは色数ではなく画素単位のざらつきである。また、後処理でフィルタをかけて平坦化するとステッチの輪郭とボタンの目が消えてしまい使えない。**最初からフラットに描く以外に成立させる方法がない。**

## 共通制作ルール（全枚数に適用）

- **フラット描画。面はすべてベタ塗り。** 紙の粒子・フェルトの繊維・布目・にじみ・グラデーション・光沢・ぼかし影・半透明グローを一切描かない。フェルトらしさは『切り口のわずかな不揃い』と『ステッチの形』だけで表す。
- **配色は下記10色のみ。** この外の色を1色も使わない。
- **解像度 720×720px**。最終180pxの4倍で描き、Claude 側が `Image.LANCZOS` で180pxへ縮小する（§9-5）。
- **背景は透過**、または均一なクロマキー。透過後に緑縁・白縁が出ないこと。
- **文字・ラベル・透かし・不要な影を入れない。**
- 全ポーズでキャラクター本体を**同じ見かけの大きさ・基準位置**にする。ポーズごとに拡大縮小して構図を整えない。
- ポーズはセル番号ではなく**共通ステージ座標**へ配置する。2×2シートで作る場合も、各マスの中でキャラクターを中央揃えし直さない（§9-5）。
- 全ポーズが**上下左右8px（720px換算で32px）の安全域**に収まること。最大動作でも見切れない。
- 本体の全高は **108px（720px換算で 432px）**、全幅 **96px（同 384px）** を基準にする。大きく描きすぎると大きな動作が安全域に収まらない。

### 2×2シートで生成する場合

1マス 720px の 2×2（全体 1440×1440px）で生成してよい。
各マスを均等にし、十分なガターを設け、何もマスをまたがせないこと。
配置後、Claude 側で `python3 scripts/split_pose_sheet.py <sheet.png> --number NNN --roles P1,P2,P3,P4` により個別ファイルへ分割する。

## 感情はステッチの状態で表す（この商品の核）

表情だけに頼らず、縫い目そのものの状態で気持ちを示す。各ポーズでどの状態にするかは「個別指示」のエフェクト欄に書いてある。

| 状態 | 見え方 |
|---|---|
| `tight` | 縫い目の間隔が詰まり、糸がぴんと張る（感謝・了解・自信・喜び） |
| `loose` | 縫い目の間隔が広がり、糸がたわむ（眠い・脱力・悲しい） |
| `frayed` | 縫い目がほどけ、糸端が数本飛び出す（照れ・寂しい・謝罪） |
| `red` | 糸の色が stitch_navy から stitch_red へ変わる（怒り・強い否定） |
| `wave` | 縫い目が波を打って走る（驚き・焦り・わくわく） |

縫い目は小さく離散的な印の集まりなので、そこだけを動かせば毎フレームの差分矩形が小さくなり、APNG が軽くなる。**感情表現と容量設計が同じ仕組みで両立している。**

## 採寸用「本体のみ版」について

`poses/NNN/P1-body.png` として、P1 から**小物・エフェクトパーツ・飛び出した糸端**を取り除いた版を1枚。
§5 のサイズ統一は主役だけのマスクで測るため、これが無いと `reports/scale-audit.csv` が算出できない（小物込みの外接矩形で測ってはならない）。
首元のリボンと縫い合わせ線は本体の一部として**残す**。除くのは小物・エフェクトパーツと、飛び出した糸端だけ。

## 記号 33〜40 について

キャラクターを描かず、`symbol_style_lock` に従う。
- 線色 `#152444` / 線幅 3.0px / 角の丸み 4.0px
- 光学面積の目標 4800px²（±12.0%）、文字系は cap height 62px
- 各パーツの縁を**ブランケットステッチでかがり、糸端を1本だけ飛び出させる**（シリーズの署名）
- 8個を色違いにしない。完成記号の変形だけで済ませず、最低5状態を作る。
