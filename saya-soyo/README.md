# Saya Soyo（さやそよ）ウェブサイト

埼玉県川口市戸塚南のカジュアルフレンチ「Saya Soyo（さやそよ）／ステージSEN」の
ホームページです。ビルド不要の静的サイト（HTML + CSS + 数行の JS）で、
外部ライブラリ・外部フォント・外部画像に一切依存していません。

```
saya-soyo/
├── index.html   # ページ本体（1ページ完結）
├── style.css    # スタイル
└── README.md    # このファイル
```

## 見る・公開する

ローカルで確認する場合:

```bash
cd saya-soyo
python3 -m http.server 8000   # http://localhost:8000
```

公開はファイルをそのままサーバーに置くだけです。
GitHub Pages / Netlify / Vercel / レンタルサーバー、いずれもそのまま動きます。

## 写真の差し替え

現在、写真は一枚も使わず CSS だけで見た目を作っています（丘のシルエット、
舞う葉っぱなど）。お店から写真をお借りできたら、次の順に入れると効果が大きいです。

1. **ヒーロー（最上部）** — 外観、または大きな窓から緑が見える店内
2. **お店について** — 料理人お二人、店内の様子
3. **お品書き** — オマール海老のトマトクリームパスタ、コースの一皿
4. **ステージSEN** — 舞台や催しの様子

`index.html` の該当セクションに `<img src="images/xxx.jpg" alt="…" loading="lazy">`
を追加し、`style.css` 側で高さと `object-fit: cover` を指定するだけで収まります。

## 実装メモ

- レスポンシブ対応（720px 以下でハンバーガーメニューに切り替え）
- スクロールに応じたフェードイン（`IntersectionObserver`）
- `prefers-reduced-motion` に対応。アニメーションを切る設定の端末では動きません
- 構造化データ（JSON-LD `Restaurant`）を埋め込み済み。検索結果に営業時間や住所が出やすくなります
- 電話番号は `tel:` リンク。スマートフォンからタップでそのまま発信できます
- OGP のタグは入れていますが、`og:image` と `canonical` の URL は公開先が決まってから設定してください
