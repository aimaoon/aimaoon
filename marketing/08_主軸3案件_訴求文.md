# 08. 主軸3案件 ファクトシート＆訴求文

> **数字はすべて2026年7月時点の調査値です。** 提携前・記事公開前に必ず公式LPとASP管理画面で
> 最新の料金・条件・報酬額を確認してください。料金改定とキャンペーンは頻繁にあります。
> 誤った金額を書くと、読者からの信用を失うだけでなく、広告主から掲載停止を受けます。

## なぜこの3案件なのか — 「価格と重さ」で棲み分ける

主軸を3つにするのは、**読者の状況が3パターンに割れるから**です。1案件だけ推すと、
残り2パターンの読者を取りこぼします。逆に10案件並べると誰も選べません。3つがちょうどいい。

```
         費用 高
          │
   Famm   │  ● 184,800円／1ヶ月集中／シッター付き
          │    「今すぐ形にしたい・子どもが小さい」
          │
 SHElikes │  ● 入会金162,800円＋月16,280円〜／50コース受け放題
          │    「何がやりたいか、まだ決まっていない」
          │
 デイトラ  │  ● 127,500円〜／買い切り・無期限／自分のペース
          │    「まず安く、独学寄りで試したい」
          │
         費用 低
```

## 案件① Famm ママ向けWEBデザイナー講座 ★最推し

### ファクトシート

| 項目 | 内容 |
|---|---|
| 料金 | **184,800円（税込）** |
| 期間 | **1ヶ月の短期集中** |
| 形式 | オンライン／対面（拠点あり） |
| **最大の特徴** | **講義中のベビーシッターが無料**（オンラインは自宅に手配、対面は近隣のキッズスペースにシッター常駐） |
| 卒業後 | **100以上の応用講座を無料で受講可能**、在宅ワーク・キャリア支援あり |
| 授業形式 | 少人数制。未経験・初心者が質問しやすい |
| 対象 | 子育て中のママ・主婦 |
| 成果地点 | 無料説明会への参加（※ASPで要確認） |
| 想定単価 | 10,000〜20,000円（※ASPで実額要確認） |
| 主な取扱ASP | A8.net / afb（※要確認） |
| 弱点（正直に書くこと） | **1ヶ月なので「卒業後すぐには稼げない」という口コミがある** |

### この案件が刺さる読者

- 子どもが未就学児で、まとまった学習時間が取れない
- 「勉強したいけど子どもを見てくれる人がいない」で止まっている
- 短期で区切りたい（ダラダラ続くと続かないと自覚している）

### 訴求の核心

**「子どもを預けられないから始められない」という最大の障害を、サービス側が消してくれる。**
これは他のスクールにない構造的な強みです。ここだけを言えばいい。

### Threads訴求文（3パターン）

**パターンA：障害の言語化型**
```
40代主婦が在宅ワークを始められない理由、
やる気でもお金でもなくて、
「子どもを見てもらえる人がいない」だと思ってます。

私も上の子の幼稚園と下の子のお昼寝の
1時間半でしか動けなかった。
その1時間半で講座を受けるって、無理です。

講義の間だけベビーシッターを
無料で手配してくれるスクールがあると知って、
「そこまでやるんだ」と正直びっくりしました。

やる気がないんじゃなくて、
条件が揃ってなかっただけかもしれません。
```

**パターンB：時間の重さ型**
```
1ヶ月で終わる、という条件だけで
選んでもいいと思ってます。

半年のコースって、
子どもがいると必ず途中で何か起きるんですよ。
熱を出す、行事が入る、自分が倒れる。

私は「まず1ヶ月」に区切れるものを選びました。
続けられるかどうかは、やる気じゃなくて
設計の問題だと思ってます。
```

**パターンC：説明会体験型（実際に受けてから書く）**
```
無料説明会、受けてきました。

正直、「どうせ最後に高額を勧められるやつだろう」
と思って身構えて行きました。

結論、料金は明確に提示されました。184,800円。
安くはないです。パート2ヶ月分です。

ただ、講義中のシッター代を自分で払ったら
それだけで数万円かかることを考えると、
見え方は変わりました。

即決はしませんでした。
夫に相談して、3日考えて決めました。
そのくらいの温度で行くのがいいと思います。
```

> パターンCが最も成約します。**必ず自分で無料説明会を受けてください。** これ以上の武器はありません。

## 案件② SHElikes（シーライクス）

### ファクトシート

| 項目 | 内容 |
|---|---|
| 入会金 | **162,800円（税込）** |
| 月額 | スタンダードプラン **月払16,280円** ／ 12ヶ月一括なら **月あたり13,567円** |
| 軽いプラン | **ライトプラン（月5回レッスン）** あり |
| コース数 | **50種類以上が受け放題**（Webデザイン、ライティング、マーケ、動画 ほか） |
| 含まれるもの | 月1回のコーチング、課題添削、お仕事チャレンジ、コミュニティ |
| 形式 | オンライン（教室拠点もあり） |
| 無料体験 | 無料体験レッスンあり。**参加特典として初月受講費用が無料**（※時期により変動） |
| 成果地点 | 無料体験レッスンの参加（※ASPで要確認） |
| 想定単価 | 10,000〜15,000円（※ASPで実額要確認） |
| 主な取扱ASP | A8.net / afb（※要確認） |
| 弱点（正直に書くこと） | **入会金が高く、初期費用の総額が大きい。**「受け放題ゆえに何も身につかない」リスクもある |

### この案件が刺さる読者

- 「何をやりたいか分からない」段階の人（← **これが一番多い**）
- 一人だと続かない自覚がある人（コミュニティが効く）
- 同世代・同じ立場の仲間が欲しい人

### 訴求の核心

**「やりたいことが決まっていない」を、欠点ではなく前提として扱う。**
40代で方向転換する人の最大の悩みは「向いてることが分からない」です。
1コースに絞らせる他スクールでは、この層は決められません。

### Threads訴求文（3パターン）

**パターンA：迷いの肯定型**
```
「何がやりたいか分からない」って、
40代で言うと怒られそうな気がしてました。

でも冷静に考えたら、
20年間ずっと家と職場を往復してた人間が
急に「私はこれで生きていく」なんて
分かるわけないんですよね。

私はデザインをやるつもりで始めて、
今はライティングをやってます。
やってみないと分からなかった。

決めてから始めるんじゃなくて、
やりながら決めていいと思ってます。
```

**パターンB：総額の正直開示型**
```
受け放題のスクール、正直に金額を書きます。

入会金 162,800円
月額 16,280円（12ヶ月一括なら実質13,567円/月）

1年やると約35万円。安くないです。

私が計算したのは
「35万を何ヶ月で回収できるか」でした。

月3万円稼げるようになるまで1年かかるとして、
その後1年で回収。トータル2年。

2年で自分に手に職がつくなら、
40代の私にとっては早い方だと思いました。

この計算に納得できない人は、
やめた方がいいと思います。本気で。
```

**パターンC：向き不向きの明示型**
```
受け放題スクールが向いてない人、
先に書いておきます。

・すでにやりたいことが1つに決まっている
　→ 単科の買い切り講座の方が安いです

・一人で黙々やる方が集中できる
　→ コミュニティ代を払う意味がないです

・月1万6千円の固定費が家計に響く
　→ 続かないと意味がないので、まず貯めてから

逆に「何から手をつければいいか分からない」
という人には、これ以上ないと思ってます。
私がそうでした。
```

## 案件③ デイトラ AI業務活用コース

### ファクトシート

| 項目 | 内容 |
|---|---|
| 講座名 | **AI業務活用コース**（2026年7月13日 開講） |
| 料金 | **早期割引 127,500円（税込）** ※2026年7月31日までの受講開始が対象。以降は通常価格 |
| 形式 | **買い切り型**。月額課金なし。**購入後カリキュラムは無期限で閲覧可能** |
| 内容 | マーケティング／デザイン／バックオフィス領域の現役プロが講師。ツール操作にとどまらない実務でのAI活用 |
| サポート | メンターによる課題添削・質問対応 |
| 対象 | 未経験可。オンライン完結 |
| 成果地点 | 講座購入（※ASPで要確認） |
| 想定単価 | 5,000〜10,000円（※ASPで実額要確認） |
| 主な取扱ASP | A8.net（※要確認） |
| 弱点（正直に書くこと） | **購入型＝成約ハードルが高い。**「無料説明会」で成果が出る案件より成約率は落ちる。自走できない人は挫折しやすい |

### ⚠️ 緊急：キャンペーン期限が近い

**早期割引の対象は2026年7月31日までの受講開始**とされています（今日は7月29日）。
使うなら**今日中に投稿**する必要があります。ただし——

- **必ず公式サイトで期限と価格を確認してから投稿してください。** 期限が変わっている可能性があります
- **ASPで提携が完了していなければ報酬は発生しません。** 未提携なら今回は見送り、
  次のキャンペーンに備えて今のうちに提携申請だけ出しておくのが正解です
- 提携が間に合わない場合、無理に投稿しないこと。焦った投稿は必ず雑になります

### この案件が刺さる読者

- 「スクールに何十万も出せない」層
- 学習ペースを自分で決めたい人
- **すでに事務・経理などの仕事をしていて、そこにAIを足したい人**（← 実は最も相性が良い）

### 訴求の核心

**「新しい仕事に転職する」ではなく「今の仕事にAIを足す」という提案。**
40代主婦の多くは、すでにパートや事務経験があります。ゼロから始めるより、
既存の経験にAIを乗せる方がはるかに現実的で、本人の抵抗も少ない。

### Threads訴求文（3パターン）

**パターンA：既存スキル活用型**
```
40代の強みって、
新しいことを覚える速さじゃなくて、
「その仕事が何のためにあるか分かってる」ことだと思ってます。

請求書を作る意味も、
議事録をまとめる意味も、
20年やってきたら体で分かってる。

そこにAIを足すと、
新卒がAIを使うのとは全然違うものが出てきます。

ゼロから何かになろうとしなくていい。
今できることの横にAIを置くだけでいいです。
```

**パターンB：買い切りの安心型**
```
月額制のサービスが苦手です。
「使ってないのに引き落とされてる」が
一番しんどいので。

買い切りで、期限なしで見られるやつを選びました。
子どもが熱を出して2週間止まっても、
罪悪感がないのが本当に大きい。

自分のペースって、
40代主婦には性能じゃなくて必需品だと思ってます。
```

**パターンC：キャンペーン便乗型（※期限と価格を必ず確認してから）**
```
［PR］

検討してた講座が、割引期間の最終週でした。

正直、割引だから買うのは反対派です。
必要ないものは安くても要らない。

ただ「いつか学ぼう」と思ってるなら、
その"いつか"は永遠に来ないので、
期限があるうちに決めるのは悪くないと思ってます。

私は3日悩んで決めました。
悩んだ時間の方が長かった。

詳細はブログにまとめました。
```

## 3案件共通のNGと必須事項

### 絶対に書かないこと

- ❌ 「卒業したら月◯万円稼げます」（成果保証＝景表法違反）
- ❌ 「未経験でも必ず案件が取れます」
- ❌ 「今だけ」を根拠なく書く（実際のキャンペーン期間のみ記載可）
- ❌ 他スクールの実名を挙げての批判
- ❌ 自分が受けていない説明会を「受けた」と書く（**絶対に）**

### 必須事項

- ✅ 冒頭に「本記事にはプロモーションを含みます」／投稿冒頭に［PR］
- ✅ 料金は**税込で正確に**。改定があれば即修正
- ✅ 各案件に**必ず「気になった点」を1つ以上**書く
- ✅ 「私の場合は」を主語にする。一般化しない
