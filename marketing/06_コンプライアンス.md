# 06. コンプライアンス — これを守らないと全部が消えます

> このドキュメントは一般的な情報の整理であり、法的助言ではありません。
> 判断に迷う表現があれば、各ASPの担当者、または専門家に確認してください。

---

## 1. ステマ規制（景品表示法）— 最重要

2023年10月1日から、広告であることを隠した投稿（ステルスマーケティング）が
景品表示法上の不当表示として規制対象になりました。**2026年現在、監視・執行は強化されています。**

### 1-1. 何がアウトか

**アフィリエイトリンクを含む投稿・記事・LINE配信は、すべて「広告」です。**
報酬が発生する以上、「個人の感想です」では逃げられません。

### 1-2. 表記のルール

| 場所 | 表記 | 位置 |
|---|---|---|
| ブログ記事 | 「本記事にはプロモーションを含みます」 | **記事冒頭**（タイトル直下） |
| Threads投稿 | 「［PR］」 | **本文の冒頭** |
| Instagram投稿 | 「#PR」または「［PR］」 | キャプション**冒頭**。タグの海に埋めない |
| ストーリーズ | 「PR」 | 画面上に視認できるサイズで |
| 公式LINE | 「［PR］」 | メッセージ冒頭 |
| プロフィールのリンク集 | 「広告を含みます」 | ページ上部 |

### 1-3. やってはいけない表記の仕方

- ❌ 記事の最後にだけ小さく書く
- ❌ ハッシュタグを30個並べた最後に「#pr」を混ぜる
- ❌ 「アフィリ」「アソシエイト」など一般消費者に伝わらない略語だけで済ませる
- ❌ 薄い色・極小フォントで書く
- ❌ 「一部プロモーションを含む場合があります」（曖昧すぎる）

**判断基準はシンプルです**: 「普通の読者が、パッと見て広告だと分かるか」。
迷ったら、目立つ位置に大きく書いてください。**PR表記でCVRは大して落ちません。**
むしろ隠している方が、バレた時に信用を全て失います。

## 2. 使ってはいけない表現

副業・在宅ワーク・お金の領域は、景表法（優良誤認・有利誤認）の監視対象です。

### 2-1. 絶対NG

| NG表現 | なぜダメか | 言い換え |
|---|---|---|
| 「必ず稼げます」 | 断定＝優良誤認 | 「私の場合は◯ヶ月で◯円でした」 |
| 「誰でもできます」 | 断定 | 「パソコンが苦手な私でもできました」 |
| 「月20万確定」 | 根拠のない断定 | 「目標は月20万です。現在は◯円」 |
| 「絶対に損しません」 | 断定 | 「私は始めてよかったと思っています」 |
| 「登録するだけで稼げる」 | 誇大 | 「登録は5分でできました」 |
| 「業界No.1」 | 根拠（調査データ）が必要 | 使わない |
| 「完全放置で自動収入」 | 誇大 | 「仕組みを作るまでは手を動かします」 |

### 2-2. 実績を語る時のルール

- **自分の実際の数字だけを書く。** 盛らない。スクショを加工しない
- 他人の成功例を書く時は「◯◯さんの例」と明示し、**それが一般的な結果ではないことを添える**
- 「個人の成果であり、成果を保証するものではありません」を実績記事に添える

### 2-3. 薬機法（美容・健康系案件を扱う場合）

主軸ではありませんが、主婦向け発信をしていると美容案件の話が来ます。手を出す場合は要注意。

- ❌ 「痩せる」「シミが消える」「治る」→ 化粧品・健康食品では**すべてNG**
- 表現規制が非常に厳しく、専門知識なしに触ると危険です
- **推奨: このアカウントでは美容・健康系案件は扱わない。** 得られる報酬に対してリスクが大きすぎます

## 3. ASP規約・広告主規約

### 3-1. SNS掲載の可否は「案件ごと」に違う

- ASPが全体としてSNS掲載を認めていても、**広告主が個別に禁止している場合があります**
- 必ず提携後の**案件詳細ページの「掲載条件」「禁止事項」を読む**
- 規約は変わります。「半年前はOKだった」は通用しません

### 3-2. 典型的な禁止事項

- リスティング広告での掲載（特に商標ワード）
- 「無料」「最安」など広告主が指定する禁止ワードの使用
- 自己アフィリエイト（セルフバックの規定外利用）
- 誤解を与えるバナー配置（誤クリックを誘う配置）
- 広告主のロゴ・画像の無断加工

### 3-3. 報酬没収を避けるために

**発生した報酬が全額取り消される最大の原因は規約違反です。**
1件でも違反があると、その月の全報酬が没収されるケースがあります。

- [ ] 新しい案件と提携したら、掲載条件を必ず読む
- [ ] 禁止ワードのリストを案件ごとにメモしておく
- [ ] 規約改定のメールは必ず開く

## 4. プラットフォーム規約（Meta / Threads / Instagram）

- 過度な外部誘導、スパム的な連投・大量フォローはアカウント制限の対象
- **同じ文面のコメント・DMを大量送信しない**（自動化ツールを使う場合は特に注意）
- 「LINE登録だけで◯万円」のような誇大表現は、プラットフォーム側の広告ポリシー違反にもなり得ます
- Instagram/Threadsのアカウントは連動しています。**片方が停止すると両方失う可能性があります**

### リスク分散

**プラットフォームは、ある日突然アカウントを止めます。理由も教えてくれません。**
だからこそ：

- 公式LINEにリストを貯める（プラットフォーム外の資産）
- ブログを持つ（自分が所有する媒体）
- LINEリストは定期的にエクスポート可能な形で管理（LINE公式アカウントも凍結し得ます）

## 5. 特定商取引法・その他

### 5-1. 自分の商品を売る場合（Phase 3以降）

アフィリエイトだけでなく、自分のnote・教材を売る段階になったら：

- 特定商取引法に基づく表記（氏名・住所・連絡先）が必要になります
- **個人の場合、原則として本名・住所の記載が必要です**
  （非開示にできる条件は限定的。バーチャルオフィス等の検討が必要）
- 「情報商材」は特にトラブルが多い領域。返金規定を明示すること

### 5-2. 税務

- 給与所得がない専業主婦の場合、**所得48万円超**で確定申告が必要（基礎控除の範囲）
- パート等の給与所得がある場合、**副業所得20万円超**で確定申告が必要
- **配偶者控除・扶養の判定に影響します。** 月20万＝年240万は扶養から確実に外れます
- 経費（サーバー代・ツール代・書籍代）の領収書は最初から保管を
- **月10万を超えそうになった時点で、一度税理士に相談することを強く推奨します**

> ここは軽視されがちですが、扶養を外れる影響（社会保険料・配偶者の手当）は
> 年間数十万円規模になり得ます。**目標を月20万に設定した時点で、
> 世帯全体の手取りシミュレーションを一度やっておいてください。**

## 6. 投稿前チェックリスト（毎回使う）

案件リンクを含む投稿・記事・配信の前に、必ず全項目を確認。

- [ ] ［PR］表記を冒頭に入れたか
- [ ] 「必ず」「誰でも」「確実に」「絶対」を使っていないか
- [ ] 断定的な収益保証をしていないか
- [ ] 実績の数字は自分の実測値か（盛っていないか）
- [ ] 他人の成果を載せる場合、一般的な結果でない旨を書いたか
- [ ] その案件の掲載条件（禁止事項）を確認したか
- [ ] 禁止ワードを使っていないか
- [ ] リンクは生きているか
- [ ] 実在サービスを名指しで批判していないか
- [ ] 美容・健康の効果効能を書いていないか

## 7. 「グレーだけど稼げる手法」を勧められた時の判断基準

必ず誘われます。判断基準を今のうちに決めておいてください。

| 手法 | 判断 |
|---|---|
| PR表記を消すとCVRが上がる | **やらない。** 一発で全部終わります |
| 実績スクショを盛る | **やらない。** バレます。40代主婦層は特に敏感です |
| 使っていない案件を紹介する | **やらない。** 質問に答えられません |
| 中身を知らない高額商材を紹介する | **やらない。** 読者が損をした瞬間に終わりです |
| 大量アカウントで拡散 | **やらない。** BAN対象かつ資産にならない |

**このビジネスの本質は、40代主婦という慎重で誠実な層からの信頼です。**
信頼を1回失うと、その人は二度と戻ってきません。
短期の数万円のために、月20万の仕組みを壊さないでください。
