# 07. KPI管理 — 見る数字と週次レビューの型

## 1. 見る数字を絞る

数字は多く取るほど何も分からなくなります。**フェーズごとに追う指標は1つだけ**にしてください。

| フェーズ | 追う指標（North Star） | 理由 |
|---|---|---|
| Phase 0 | ブログ記事数 | 土台がないと何も始まらない |
| Phase 1 | **Threadsフォロワー増加数/週** | まず母数。収益は見なくていい |
| Phase 2 | **公式LINE登録数/月** | ここが収益に直結するボトルネック |
| Phase 3 | **確定報酬額** | 仕組みが回り始めたら結果だけ見る |

> Phase 1で報酬額を毎日見るのは、最も効率よく心が折れる方法です。**見ないでください。**

## 3. ボトルネックの見つけ方

数字が悪い時、どこを直すかを機械的に判断する表。

| 症状 | ボトルネック | 打ち手 |
|---|---|---|
| インプレッションが伸びない | 投稿の冒頭2行 | [05](./05_コンテンツ設計.md)の書き出し型を総入れ替え。1日リプ10件に増やす |
| impはあるがフォローされない | プロフィール文 | プロフィールを書き直す。「何の人か」を3秒で分かるように |
| フォロワーは増えるがプロフィール遷移が1%未満 | 投稿に「続きが気になる」要素がない | 案2（コメント配布型）・案3（ツリー型）を増やす |
| 遷移はあるがリンククリックが10%未満 | リンク集の見せ方 | 選択肢を1つに絞る。プレゼントの見出しを具体化 |
| クリックはあるがLINE登録が30%未満 | プレゼントが弱い | リードマグネットを作り直す（[03](./03_導線設計.md)参照） |
| LINE登録はあるが成約0 | ステップ配信 | 4通目までを書き直す。売り込みが早すぎないか確認 |
| 発生はあるが承認されない | 案件のミスマッチ | 承認率50%未満の案件を撤退。承認条件を読み直す |
| 全部良いのに報酬が少ない | 単価 | 特別単価交渉。A層（高単価）案件を1つ追加 |

**上から順に潰してください。** 下の問題を先に触っても効きません。

## 4. A/Bテストの回し方

同時に複数を変えると何が効いたか分かりません。**1回に1要素だけ。**

### テストしやすく効果が大きい順

1. **投稿の書き出し2行** — 同じ内容で2パターン。1週間ずらして投稿し、impを比較
2. **投稿時間** — 朝7時 vs 夜21時。2週間ずつ回す
3. **リンク集の見出し** — 「無料ガイド」vs「40代主婦のための在宅ワーク完全ガイド」
4. **リードマグネット** — プロンプト集 vs 比較シート。登録率を比較
5. **ステップ配信の4通目** — 案件を紹介するタイミングを5日目 vs 7日目

## 5. 月次レビュー（毎月1日 60分）

### 5-1. 数字の確認

- [ ] [00_収益設計.md](./00_収益設計.md) の記録テンプレに前月実績を記入
- [ ] 承認率を案件ごとに確認 → 50%未満の案件をリストアップ
- [ ] リンク切れの全チェック（ブログ・LINE・ハイライト）

### 5-2. 案件の入れ替え判断

| 判断 | 基準 |
|---|---|
| **継続** | 発生あり かつ 承認率50%以上 |
| **強化** | 発生が全体の20%以上 → 専用記事を追加、ステップ配信に組み込む |
| **様子見** | クリックはあるが発生0（1ヶ月目） |
| **撤退** | クリック多数・発生0が2ヶ月／承認率50%未満／単価が下がった |

### 5-3. コンテンツの棚卸し

- [ ] 伸びた投稿トップ5を抽出 → 共通点を言語化 → 来月の型にする
- [ ] 伸びた投稿を1ヶ月後にリライトして再投稿する予約を入れる
- [ ] ブログ記事のうち、順位が上がってきた記事にリンクを追加・強化

## 6. 月20万到達までの中間マイルストーン

| 到達点 | 目安時期 | 意味 |
|---|---|---|
| 初報酬 1円 | 2〜3ヶ月目 | **最大の壁。** ここを超える人が半分 |
| 月1万円 | 4ヶ月目 | 仕組みが動き始めた証拠 |
| 月3万円 | 5〜6ヶ月目 | サーバー代・ツール代を回収 |
| 月5万円 | 6〜7ヶ月目 | 「副業」として家計に効き始める |
| 月10万円 | 8〜9ヶ月目 | ステップ配信が機能している証拠 |
| 月20万円 | 10〜12ヶ月目 | **ゴール。** ここから稼働時間の圧縮に入る |

> 各マイルストーンを達成したら、必ずその日のことを投稿に残してください。
> それ自体が最高のコンテンツになり、次の読者を連れてきます。

## 7. 折れそうになった時に見る場所

数字が動かない時期は必ず来ます。その時に確認すること。

1. **累計の投稿数を数える。** 90本未満なら、まだ判断するには早すぎます
2. **1ヶ月前の自分の投稿を読み返す。** 文章は確実に上手くなっています
3. **[00_収益設計.md](./00_収益設計.md)の記録テンプレを見る。** インプレッションは伸びているはずです
4. **もらったコメントを読み返す。** 数字にならなくても、届いている人がいます

このビジネスで最も多い失敗は、規約違反でも案件選定ミスでもなく、
**「成果が出る直前でやめること」**です。

Phase 1の3ヶ月は、ほぼ全員が「意味あるのかな」と思いながら投稿しています。
そこを越えた人だけが Phase 2 に行きます。
