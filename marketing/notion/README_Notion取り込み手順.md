# Notion 取り込み手順

このフォルダは、`marketing/` の内容を **Notionで実際に使える形** に整形したものです。
パソコンでもスマホでも、チェックを付けたり数字を書き込んだりしながら運用できます。

---

## このフォルダの中身

```
notion/
├── pages/       … 読み物（13ファイル）→ Notionページとして取り込む
└── databases/   … 書き込む表（7ファイル）→ Notionデータベースとして取り込む
```

**この2つは取り込み方法が違います。** 順番に説明します。

---

## STEP 0｜ファイルをダウンロードする（5分）

1. パソコンで GitHub のリポジトリを開く
2. 緑色の **「Code」** ボタン → **「Download ZIP」**
3. ダウンロードした ZIP を解凍
4. `marketing/notion/` フォルダの中身を使います

> スマホだけでもできますが、**最初の取り込みはパソコンを強く推奨します。**
> 一度取り込んでしまえば、あとはスマホアプリで完結します。

---

## STEP 1｜読み物を取り込む（10分）

`pages/` の中の13ファイルを、Notionページとして取り込みます。

1. Notionを開き、左サイドバーで **新しいページ** を作る
2. ページ名を「**AIアフィリエイト運用**」にする
3. 左サイドバー下部の **「インポート」** をクリック
4. **「Markdown」** を選ぶ
5. `pages/` の中の **13ファイルを全部まとめて選択** → 開く
6. 数十秒待つと、13ページが作られます
7. 作られたページを、STEP 2 で「AIアフィリエイト運用」の下にドラッグして整理

### 取り込まれるページ

| ファイル | 中身 |
|---|---|
| README | 全体マップ・チーム役割 |
| 00_収益設計 | 月20万の逆算・フェーズ別ロードマップ |
| 01_ASP申請ロードマップ | 申請の準備と順序 |
| 02_案件リスト30 | 案件30選の解説 |
| 03_導線設計 | Threads→IG→LINEの設計図 |
| 04_リンク訴求12案 | 訴求パターンと文面例 |
| 05_コンテンツ設計 | 投稿テンプレ・カレンダー |
| 06_コンプライアンス | ステマ規制・NG表現・税務 |
| 07_KPI管理 | 見る数字・ボトルネック診断 |
| 08_主軸3案件_訴求文 | Famm/SHElikes/デイトラの訴求文 |
| 09_プロンプト集50 | 配布物の完成原稿 |
| 10_ステップ配信7通 | LINE配信の全文 |
| 11_Threads初月90投稿 | 90本の全原稿 |

> **ページ同士のリンクは外してあります。** Markdownのファイル間リンクはNotionでは切れるためです。
> 代わりに本文中では「「07_KPI管理」ページ」のように名前で参照しています。
> 気になる場合は、Notion上で `@ページ名` と打てば本物のリンクに置き換えられます。

## STEP 2｜書き込む表を取り込む（15分）★ここが本命

`databases/` の7ファイルは、**CSVとして取り込むとNotionのデータベースになります。**
ここが「Notionにする意味」の9割です。並べ替え・絞り込み・スマホからの入力ができるようになります。

### 取り込み方（1ファイルずつ）

1. 「AIアフィリエイト運用」ページの中で `/データベース` と打ち、**「データベース - フルページ」** を作る
   （または左サイドバー下部の **「インポート」→「CSV」** でも可）
2. CSVファイルを選ぶ
3. 取り込まれたら、各列の **プロパティの種類** を設定する（下表）

### 各データベースの設定

#### ① `db_投稿カレンダー90.csv` — **一番使います**

90投稿が1行ずつ入っています。本文もそのまま入っているので、**開いてコピーするだけで投稿できます。**

| 列 | 種類 | 設定 |
|---|---|---|
| 投稿ID | タイトル | そのまま |
| 日 | 数値 | |
| 時間帯 | セレクト | 朝／昼／夜 |
| 投稿時刻 | セレクト | 07:00／12:00／21:00 |
| 分類 | セレクト | 共感／ノウハウ／プロセス／日常／導線 |
| 書き出し型 | セレクト | |
| 本文 | テキスト | **改行が入っているので幅を広めに** |
| 状態 | セレクト | 未着手／執筆済／**予約済**／投稿済 |
| インプレッション／いいね／リプライ | 数値 | 投稿後に記入 |
| メモ | テキスト | |

**作っておくと便利なビュー**
- 「**今週の投稿**」… 日 で絞り込み、時間帯で並べ替え
- 「**未着手だけ**」… 状態 = 未着手
- 「**伸びた順**」… インプレッションの降順 → 月末の振り返りで使う

#### ② `db_案件管理30.csv`

| 列 | 種類 | 設定 |
|---|---|---|
| 案件名 | タイトル | |
| 層 | セレクト | A／B／C／D／E |
| 着手フェーズ | セレクト | Phase1／Phase2／Phase3／保留 |
| 提携状況 | セレクト | 未申請／申請中／**提携済**／却下 |
| 判定 | セレクト | 継続／強化／様子見／**撤退** |
| 実単価・累計発生 | 数値 | ASP管理画面から転記 |
| 承認率 | 数値（％表示） | **50%未満は撤退** |

> **最初は「着手フェーズ = Phase1」で絞り込んでください。** 表示されるのは4案件だけです。
> 30件を一度に見ると必ず手が止まります。

#### ③ `db_ASP申請トラッカー.csv`
審査結果を「未申請／申請中／通過／却下」のセレクトに。**却下になったら2週間空けて再申請**です。

#### ④ `db_KPI週次記録.csv`
12週分の空行が入っています。毎週日曜に1行埋めるだけ。数値列はすべて「数値」に設定を。

#### ⑤ `db_ステップ配信.csv`
7通＋あいさつの執筆・設定状況。開封率／クリック率／ブロック率を記録します。

#### ⑥ `db_訴求12案.csv`
どの訴求パターンを試したか。「採用」を 未検証／検証中／**採用**／不採用 のセレクトに。

#### ⑦ `db_ネタバンク30.csv`
投稿ネタの在庫。「再利用可」を 未使用／使用済／**再利用OK** に。ネタ切れのときここを見ます。

## STEP 3｜スマホアプリを入れる（3分）

Notionのスマホアプリを入れて同じアカウントでログインすれば、取り込んだものが全部出てきます。

**スマホでやること**
- 朝：`db_投稿カレンダー90` を開いて今日の投稿をコピー → Threadsに貼る
- 投稿後：その行の「状態」を「投稿済」に変える
- 夜：インプレッションを記入

**パソコンでやること**
- 日曜：翌週21投稿の【　】を埋める、KPIを1行記入
- 月初：案件管理の承認率を更新、撤退判断

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| CSVを開いたら文字化けした | Notionに取り込む分には問題ありません。Excelで開きたい場合のみ「データ」→「テキストファイル」からUTF-8を指定 |
| 本文の改行が消えた | 列の種類が「テキスト」になっているか確認。セレクトや数値だと崩れます |
| 表がただの表のまま（並べ替えできない） | Markdownの表を取り込んだページです。並べ替えたい表はCSV版（`databases/`）を使ってください |
| ページ内のリンクが文字になっている | 仕様です。`@ページ名` で本物のリンクに置き換えられます |
| 90投稿が重くて開かない | ビューを「今週の投稿」に絞ってください。全件表示は月1回で十分です |

---

## 元ファイルとの関係

- **`marketing/` 直下のmdファイルが原本**です。内容を大きく直すときはそちらを更新
- **`notion/pages/` は原本から自動生成した複製**です。ここを直しても原本には反映されません
- Notionに取り込んだ後は、**Notion側が運用の正**になります。原本は「元の設計書」として残す扱いで構いません
