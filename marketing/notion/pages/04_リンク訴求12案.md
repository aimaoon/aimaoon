# 04. リンク訴求パターン12案 — 具体文面つき

「どうやってリンクに送るか」の実戦パターン集。
**全部を同時に使わないこと。** 週に2〜3パターンを回して、数字が出たものを主力にします。

各パターンの見方：
- **難易度** ★=すぐできる ★★★=仕組みが要る
- **想定CVR** = リンククリック→登録/成約の目安。あくまで初期の想定値で、実測で上書きしてください

---

## 案1｜プロフィール一点集中型（基本形）

**難易度 ★｜想定CVR 中｜使う場所：Threads本文**

投稿本文にリンクを一切貼らず、プロフィールへ集約する最も安全で再現性の高い型。

**文面例**
```
「AIで副業」って調べたけど、
出てくるのが全部20代の話で心が折れた40代です。

パソコンはExcelがギリ。
スマホは子どもに教わる。
そんな私が半年やってみて、
実際に使えたものだけまとめました。

ちなみに一番いらなかったのは
「高額なパソコン」でした。
今も5年前のノートPCです。

まとめはプロフィールに置いてます📎
```

**ポイント**
- 「プロフィールに置いてます」は最後の1行だけ。押し付けない
- 冒頭2行で「40代」「心が折れた」と自己開示 → 同じ属性の人が止まる
- 「一番いらなかったのは」で意外性を作り、最後まで読ませる

**注意**: これを毎投稿でやると宣伝アカウント認定されます。**3投稿に1回まで。**

---

## 案2｜コメント欄配布型

**難易度 ★｜想定CVR 高｜使う場所：Threads**

本文はリンクなしで完結させ、リンクは自分で最初のコメントに置く（またはコメントを求める）。

**文面例（本文）**
```
ChatGPTに「主婦の1日の献立を考えて」って
雑に投げても微妙なものしか出てこないけど、

・冷蔵庫にあるもの
・調理時間の上限
・家族の好き嫌い

この3つを足すだけで急に使えるようになります。

同じ要領で「在宅ワークの探し方」を
聞くためのプロンプト、50個まとめました。

「50」ってコメントもらえたら、
まとめたやつのリンク送ります👋
```

**ポイント**
- **コメント数がアルゴリズム上の最強シグナル。** これが本当の狙い
- 「50」など短い単語を指定する（打つのが楽＝ハードルが下がる）
- 返信は必ず手動 or 自動応答で。返さないと信用を失います

**注意**: コメント返信でリンクを送る場合も、ASP直リンクではなく**LINE or ブログ**へ。

## 案3｜リプライツリー型

**難易度 ★｜想定CVR 中｜使う場所：Threads**

1投稿目でバズを狙い、自分のリプライ（2投稿目）に情報とリンクを置く。

**構成**
```
【1投稿目】← ここでインプレッションを取る
40代で在宅ワーク始めて一番驚いたのは、
「若い人と競争しなくていい」ってことでした。

主婦の経験そのものが強みになる仕事、
実はけっこうあります。

  └【2投稿目：自分でリプ】
    具体的にはこの3つ。
    ①事務代行 ②カスタマーサポート ③レシピ・生活系ライティング
    どれも「段取り力」と「気遣い」が評価される領域です。
    
    求人の探し方はプロフィールのリンクにまとめました。
```

**ポイント**
- 1投稿目に売り気配をゼロにする（バズの邪魔になる）
- 2投稿目は1投稿目が伸びてから追加してもよい

## 案4｜公式LINEステップ配信型（本命・自動化の核）

**難易度 ★★★｜想定CVR 最高｜使う場所：LINE**

**これが月20万の主軸です。** 他の11案は全部これに人を集めるための手段だと考えてください。

**文面例（ステップ6通目：スクール案件への橋渡し）**
```
［PR］

こんばんは、◯◯です。

前回、「独学でもいけますか？」って
質問をたくさんいただいたので、
今日は正直な話をします。

結論から言うと、独学でいけます。
私も最初の3ヶ月は独学でした。

ただ、独学には向き不向きがあって、

▼独学が向いている人
・まとまった時間が取れる
・分からないことを自分で調べるのが苦じゃない
・半年〜1年かけてもいい

▼スクールが向いている人
・子どもがいて時間が細切れ
・「何が分からないか」が分からない
・3ヶ月で形にしたい

私は完全に後者でした。
夜11時に調べ物をしていて、
「この時間、聞ければ5分で終わるのに」
と何度も思ったので。

無料説明会だけ受けてみる、でも十分です。
私が実際に受けたところの話は、次回書きます。

▼今日の内容の詳しい比較はこちら
https://（自分のブログの比較記事）
```

**ポイント**
- **両論併記が信頼を生む。** 「独学は無理」と言った瞬間に売り込みになります
- 自分が後者だったと開示することで、同じ人が自分を重ねる
- リンクは1つだけ、ブログの比較記事へ（LINEに直アフィリを貼らない設計）
- 冒頭の［PR］を絶対に忘れない

## 案5｜比較記事送客型

**難易度 ★★｜想定CVR 高｜使う場所：Threads→ブログ**

「◯◯と△△、どっちがいい？」は最も検索され、最も成約する型。

**文面例（Threads）**
```
クラウドワークスとランサーズ、
両方3ヶ月使ってみた結論。

初心者はクラウドワークス、
単価を上げたいならランサーズ。

理由は「案件数」じゃなくて
「クライアントの層」が違うからです。

私は最初クラウドワークスで
文字単価0.3円から始めて、
今はランサーズで1.5円まで来ました。

数字の細かい比較はブログにまとめてます。
（プロフィールから）
```

**ポイント**
- **両方を実際に使ってから書く。** 使わずに書いた比較記事は読者にバレます
- 「理由は◯◯じゃなくて△△」の構文が、素人っぽさを消します
- ブログ記事内でB層2案件を同時に回収できる（効率が良い）

---

## 案6｜Instagramストーリーズ＋ハイライト型

**難易度 ★｜想定CVR 中｜使う場所：Instagram**

ストーリーズは24時間で消えますが、**ハイライトに保存すれば永続的な導線**になります。

**構成（5枚）**
```
1枚目：問題提起「在宅ワーク、探し方が分からない問題」
2枚目：共感「求人サイト見ても怪しいのばっかり…」
3枚目：解決「主婦専門のサイトがあるの知ってました？」
4枚目：実演（実際の画面スクショ）
5枚目：リンク「詳しくはこちら」＋［PR］表記
```

**ポイント**
- 5枚目まで見る人は少ないが、**そこまで見た人のCVRは非常に高い**
- 必ずハイライト「おすすめ」に保存する。作ったら資産になります
- 各枚に［PR］を入れる（消える前提でも必要）

---

## 案7｜アンケート・質問箱起点型

**難易度 ★｜想定CVR 高｜使う場所：Instagramストーリーズ**

先に聞いて、答えた人に返す。**押し売り感が完全に消える最強の型。**

**流れ**
```
【ストーリーズ アンケート】
「在宅ワーク、一番の悩みは？」
 A. 何から始めればいいか分からない
 B. 怪しい求人が怖い
 C. 時間が取れない

　↓ 数時間後

【回答結果を共有】
「Aが62%でした。同じ人が多くて安心した…」

　↓

【Aの人向けの回答ストーリーズ】
「Aの方向けに、私が最初にやった3ステップを
　まとめました。リンクから見れます」［PR］
```

**ポイント**
- 答えた人は「自分のために作られた」と感じるのでCVRが跳ね上がります
- アンケートの反応データがそのまま次の投稿ネタになります（一石二鳥）

---

## 案8｜リール保存誘導 → DM自動応答型

**難易度 ★★｜想定CVR 高｜使う場所：Instagram**

「コメントしたらDMで送ります」の型。Instagramのアルゴリズムに最も効きます。

**文面例（リールのキャプション）**
```
ChatGPTで在宅ワークの応募文を10秒で書く方法🖊️

パート応募も、クラウドソーシングの提案文も、
これで通過率が変わりました。

使ったプロンプトは長いので、
「応募文」ってコメントいただけたら
DMでそのまま送ります📩

#40代主婦 #在宅ワーク #ChatGPT活用 #副業初心者
```

**ポイント**
- コメント＋DM＋保存の3つが同時に発生し、リーチが大きく伸びます
- DMの中身は「プロンプト＋LINEへの案内」。ここでいきなり売らない
- 自動応答ツールを使う場合も、たまに手動で個別返信を混ぜると効果が上がります

## 案9｜プロセス公開型（作業ログ）

**難易度 ★｜想定CVR 中（ただし長期の信頼構築に最強）｜使う場所：Threads / IG**

完成品ではなく、途中経過を出す。40代主婦層はこの誠実さに最も反応します。

**文面例**
```
【在宅ワーク 34日目】

今日の作業：2時間
今日の収入：0円
今月の累計：1,240円

正直、時給換算したら泣けます。

でも先週書いた記事に
初めてコメントがついて、
「参考になりました」って。

たぶんこれで続けられます。

来月には1万円いきたい。
```

**ポイント**
- **稼げていない時期こそ発信価値がある。** ここで積んだ信頼が半年後に効きます
- 数字を正直に出すことで、後で成果が出た時の説得力が桁違いになります
- リンクは貼らない。これは信頼を貯める投稿です

---

## 案10｜失敗談・逆張り型

**難易度 ★｜想定CVR 中｜使う場所：Threads**

「稼げます」があふれる中で、「これはやめとけ」は圧倒的に目立ちます。

**文面例**
```
40代主婦がやらなくていい副業、正直に3つ。

①ポイ活（時給50円。子どもの寝かしつけの方が価値ある）
②単価0.1円のライティング（消耗するだけ）
③「LINE登録だけで月10万」系（全部これ）

私は①と②を4ヶ月やって、
合計で8,000円でした。

その4ヶ月をAIの勉強に使っていたら、
と今でも思います。

じゃあ何をやるか、は
プロフィールのリンクにまとめました。
```

**ポイント**
- ③で「LINE登録だけで月10万」を否定することで、
  **自分のLINEが"そうではない"ものとして位置づけられます。** これが効きます
- 自分の失敗を先に出すので、批判ではなく体験談として読まれます
- **注意**: 特定の実在サービスを名指しで批判しないこと。法的リスクがあります

---

## 案11｜期間限定・キャンペーン便乗型

**難易度 ★★｜想定CVR 最高（瞬間風速）｜使う場所：全チャネル**

ASPが出すキャンペーン情報を拾って、期限を武器にする。

**使えるタイミング**
- サーバーの割引キャンペーン（ConoHa WING等は頻繁にやります）
- スクールの入会金無料キャンペーン
- 証券口座のタイアップ増額（ASP側の特別単価）
- 新NISA・確定申告など季節要因

**文面例**
```
サーバー代の話です。

私がブログ始めた時は月1,200円くらいでしたが、
今キャンペーンで月◯◯◯円になってます。

正直、この価格なら
「合わなかったらやめる」でも損しない金額。

私は月3,000円のパート代を削って始めましたが、
今はそれ以上返ってきています。

◯月◯日までみたいです。
詳細はブログに書きました。［PR］
```

**ポイント**
- **煽らないこと。** 「今すぐ！」「絶対損します！」は逆効果かつ景表法リスク
- 「損しない金額」という言い方で、リスクの小ささを伝える
- キャンペーン情報はASPのメルマガで来ます。**必ず受信設定をONに**

## 案12｜Q&A回収型（読者の質問を投稿にする）

**難易度 ★｜想定CVR 高｜使う場所：全チャネル**

もらった質問に答える形。**最も自然にリンクを差し込めます。**

**文面例**
```
Q.「パソコンが古いのですが大丈夫ですか？」

A. 私は2019年のノートPC（メモリ8GB）で
　　全部やってます。大丈夫です。

　　ただChatGPTを使う場合、
　　ブラウザのタブを開きすぎると重くなるので、
　　そこだけ注意です。

　　あと「買い替えないと始められない」と思って
　　止まってる方、それが一番もったいないです。
　　私も半年止まってました。

　　同じような質問をLINEでたくさんいただくので、
　　初心者向けのQ&Aをまとめました。
　　（プロフィールから見れます）
```

**ポイント**
- 実際に質問が来ていなくても、「よくある不安」を質問形式にして構いません
- 質問に答える＝リンクを出す正当な理由になるので、押し売り感がゼロ
- **質問はストックしておく。** ネタ切れ対策として最強です

## 12案の使い分けマトリクス

| フェーズ | 主に使う案 | 狙い |
|---|---|---|
| Phase 1（認知） | 案9・案10・案3 | リンクを貼らずに信頼とフォロワーを貯める |
| Phase 1後半 | 案2・案7・案8 | コメント/DMでエンゲージを稼ぎつつLINEへ |
| Phase 2（収益化） | 案1・案5・案6・案12 | ブログとLINEへ本格送客 |
| Phase 3（自動化） | 案4・案11 | ステップ配信で自動販売。キャンペーンで瞬間的に伸ばす |

## 全案共通の禁止事項

- ❌ ［PR］表記なしで案件リンクへ誘導する（景表法違反）
- ❌ 「必ず」「誰でも」「確実に」「絶対」を使う
- ❌ 実在しない実績・スクショを作る
- ❌ 1投稿に複数のリンクを入れる（全部踏まれなくなります）
- ❌ 自分が使っていない・調べていない案件を紹介する

詳細は 「06_コンプライアンス」ページ を必ず確認してください。
