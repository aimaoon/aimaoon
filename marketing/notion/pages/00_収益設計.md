# 00. 収益設計 — 月20万円の逆算

## 1. 結論：どの組み合わせで20万を作るか

「単価の高い案件だけ」でも「無料登録案件だけ」でも20万は組めません。3層に分けます。

| 層 | 役割 | 案件例 | 単価目安 | 月間目標件数 | 月間報酬 |
|---|---|---|---|---|---|
| **① 主軸（高単価）** | 売上の柱 | 生成AIスクール／Webデザイン講座 | 10,000〜30,000円 | 8件 | 120,000円 |
| **② 中軸（中単価）** | 安定収入 | サーバー・ツール・証券口座 | 3,000〜10,000円 | 12件 | 50,000円 |
| **③ 入口（低単価・無料）** | 承認率と実績づくり | 在宅ワーク求人登録・クラウドソーシング | 500〜1,500円 | 30件 | 30,000円 |
| | | | | **合計** | **200,000円** |

**なぜ3層必要か**
- ①だけだと成約が月0件の月が発生し、精神的に折れる
- ③だけだと件数を稼いでも20万に届かない（500円×400件は非現実的）
- ③で「この人の紹介で登録すると良いことがある」という体験を作り、①へ引き上げる

---

## 2. 逆算：この数字を作るには何人必要か

### 2-1. ファネル全体の想定数値（6〜9ヶ月目の到達イメージ）

```
Threads 月間インプレッション          150,000
    ↓ プロフィール遷移率 2.0%
プロフィール訪問                        3,000
    ↓ リンククリック率 20%
リンク集/LP 到達                          600
    ↓ 公式LINE登録率 50%
公式LINE 新規登録                         300 人/月
    ↓
公式LINE 累計リスト（6ヶ月累積）        1,200 人
    ↓ 月間の全体成約率 4%（新規＋既存リストへの配信）
月間成約件数                             約50件
    ↓ 平均報酬単価 4,000円
月間報酬                              200,000円
```

### 2-2. 数字の見方

- **ボトルネックは「LINE登録数」です。** ここが月300人を超えると20万が見えます。
- 平均単価4,000円は、①②③のミックス平均。高単価が1件増えると一気に楽になります。
- 「累計リスト」がストックとして効くのが自動化の正体。新規流入が止まっても、
  過去のリストへのステップ配信が回り続けるので、収益がゼロにはなりません。

### 2-3. 逆に、これだけは信じないこと

- 「フォロワー1万人＝月20万」ではありません。**フォロワー数とリスト数は別物**です。
  フォロワー3,000人でリスト1,500人のアカウントは、フォロワー2万人でリスト100人より稼ぎます。
- Threadsのインプレッションは変動が激しく、月ごとに3倍違うこともあります。
  だからこそLINEにストックすることが生命線になります。

## 3. フェーズ別ロードマップ

### Phase 0：基盤構築（0〜1ヶ月目） 目標報酬 0円

やること：**売る前に、売れる場所を作る**

- ブログ開設（独自ドメイン／WordPress）
- ASP登録・審査通過（A8/もしも→afb/バリューコマース/アクセストレード）
- Threads・Instagramアカウント設計
- 公式LINE開設、あいさつメッセージのみ設置
- 記事10本（後述の型）

> ここで焦って売りに行かないこと。実績も信頼もない状態のリンクは踏まれません。

**この期間の勝利条件**: 主要ASP3社以上に通過。ブログ記事10本。Threadsフォロワー500人。

---

### Phase 1：認知獲得（2〜3ヶ月目） 目標報酬 1〜3万円

やること：**「40代主婦でAI詳しい人」として認識される**

- Threads 1日3投稿（うち1本は必ず「自分の実体験」）
- Instagram フィード週3投稿＋ストーリーズ毎日
- 無料登録系案件（③層）で初報酬を出す ← これが最重要
- 公式LINEへの誘導を開始（プレゼント設計）

**この期間の勝利条件**: Threadsフォロワー3,000人。LINE登録100人。初報酬発生。

> **初報酬を早く出すことに全力を注いでください。** 金額は500円でいい。
> 「アフィリエイトは本当に発生する」という体験がないと、Phase 2の作業量に耐えられません。

---

### Phase 2：収益化（4〜6ヶ月目） 目標報酬 5〜10万円

やること：**リストを積み、高単価に引き上げる**

- LINEステップ配信を7通完成させる（「03_導線設計」ページ参照）
- ①層（スクール系）の比較記事をブログに3本
- Threadsのバズ投稿の型を3つ確立し、使い回す
- Instagramリールを週2本（保存数を追う）

**この期間の勝利条件**: LINEリスト600人。月間成約20件。高単価案件で初成約。

---

### Phase 3：自動化と拡大（7〜12ヶ月目） 目標報酬 15〜20万円

やること：**人力部分を削り、仕組みに任せる**

- ステップ配信を14通に拡張、セグメント配信を導入
- 反応の良い投稿をテンプレ化し、AIで量産→自分は最終チェックのみ
- 案件を絞り込む（30案件→稼働8案件へ集中）
- 単価交渉（発生実績が出たらASP担当者に特別単価を打診。これが効きます）

**この期間の勝利条件**: 月20万到達。稼働時間を週8時間以下に圧縮。

---

## 4. 撤退・見直しの基準

感情ではなく数字で判断するためのライン。

| 状況 | 判断 |
|---|---|
| 3ヶ月でThreadsフォロワー1,000人未満 | 発信テーマがズレている。ペルソナを見直す |
| LINE登録率が10%未満 | プレゼント（リードマグネット）が弱い。作り直す |
| クリックはあるが成約0が2ヶ月続く | 案件とペルソナのミスマッチ。案件を差し替える |
| 特定案件の承認率が50%未満 | その案件は撤退。承認されない案件に時間を使わない |
| 6ヶ月で報酬5万円未満 | 主軸案件を①層から見直す（単価より「売れやすさ」を優先） |
