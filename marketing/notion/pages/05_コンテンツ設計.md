# 05. コンテンツ設計 — 投稿テンプレと30日カレンダー

## 1. Threads投稿の黄金構成

Threadsはタイムラインで**冒頭2行しか表示されません。** ここで止まらなければ、以降は存在しないのと同じです。

```
【1行目】共感 or 意外性（ここで止める）
【2行目】もう少しだけ引っ張る
──── ここまでがプレビュー ────
【本文】体験・具体・数字
【締め】問いかけ or 静かな導線
```

### 1行目に使える型（コピペ可）

| 型 | 例 |
|---|---|
| 自己否定 | 「パソコン苦手な40代が言うのもなんですが、」 |
| 意外性 | 「在宅ワークで一番いらなかったのは、やる気でした。」 |
| 数字 | 「4ヶ月やって8,000円でした。」 |
| 時間 | 「夜11時、子どもが寝てからの2時間の話です。」 |
| 逆張り | 「AI副業、40代主婦にはおすすめしません（条件つきで）」 |
| 質問 | 「『在宅ワーク』で検索して、心折れた人いますか？」 |
| 告白 | 「正直に言うと、最初の3ヶ月は詐欺だと思ってました。」 |

## 2. 投稿の5分類（バランス配分）

1日3投稿×30日＝90投稿。この配分で回します。

| 分類 | 割合 | 本数/月 | 目的 |
|---|---|---|---|
| **共感系** | 40% | 36本 | 「これ私だ」でフォローされる。伸びの主力 |
| **ノウハウ系** | 25% | 22本 | 「役に立つ」で保存・信頼される |
| **実績・プロセス系** | 20% | 18本 | 「本物だ」の証明。長期の信頼 |
| **人柄・日常系** | 10% | 9本 | 「人間だ」の証明。親近感 |
| **導線系** | 5% | 5本 | リンクへの誘導。**これ以上増やすと嫌われます** |

> **導線系は月5本まで。** ここを守れるかどうかが、1年続くアカウントかどうかの分かれ目です。

## 3. 投稿テンプレート集

### テンプレA｜共感系

```
【1行目：状況の描写】
【2行目：その時の気持ち】

【具体的なエピソード（3〜5行）】

【今はどう思っているか】

【問いかけ or 独り言で締め】
```

**実例**
```
子どもが寝た後の2時間だけが自分の時間で、
その2時間で何かを始めるって、想像以上に重いです。

洗い物が残ってる。
明日のお弁当も考えてない。
なのにパソコン開いてる自分に、
「何やってんだろ」って何回も思いました。

半年経った今も、たまに思います。
ただ、今は「何やってんだろ」の後に
「でも先月より進んでる」が来るようになりました。

同じ時間帯に起きてる人、いますか。
```

---

### テンプレB｜ノウハウ系

```
【1行目：結論】
【2行目：意外性のある理由】

【手順 or ポイントを箇条書き3つ】

【自分の実例（数字入り）】

【注意点を1つ正直に】
```

**実例**
```
ChatGPTに「〜してください」だけ書くのをやめたら、
返ってくる内容が別物になりました。

足すのはこの3つだけ。
①相手は誰か（例：40代の在宅ワーク初心者）
②どんな形式か（例：箇条書きで5つ）
③何を避けたいか（例：専門用語は使わない）

これで応募文を書いたら、
提案の返信率が2件/20件 → 5件/15件になりました。

ただ、AIが書いたままだと必ずバレます。
最後に自分の言葉で1文足すのは必須です。
```

---

### テンプレC｜実績・プロセス系

```
【◯日目】

今日の作業：
今日の成果：
累計：

【今日あったこと（正直に）】

【明日やること】
```

---

### テンプレD｜人柄・日常系

```
【AIとは全然関係ない日常の1コマ】

【そこから思ったこと】

【軽い締め】
```

**実例**
```
中学生の娘に「ママ、AIとか言ってるけど
LINEのスタンプ探すの遅くない？」
と言われました。

事実です。

でも、遅くても半年やれば
それなりに形になるって、
今なら娘に胸を張って言えます。

スタンプは今も遅い。
```

> **このテンプレDを侮らないでください。** 実は最も伸びる投稿はここから出ます。

| 日 | 朝 7:00 | 昼 12:00 | 夜 21:00 |
|---|---|---|---|

| 5 | 共感：40代で始める不安 | ノウハウ：プロンプトのコツ | プロセス |
| 6 | Q&A：よくある質問① | 共感：パート時代の話 | 日常 |

| 8-14 | （同じリズムで反復。ネタは下の「ネタ出し30」から） | | |

| 22 | **導線③**：ブログ記事の紹介 | | |
| 29 | **導線④**：月次まとめ＋LINE | | |

**運用のコツ**
- 日曜の夜に**翌週21投稿をまとめて作る**（毎日考えると必ず折れます）
- 予約投稿ツールを使う（Threadsは公式の予約機能が限定的なので、外部ツールを検討）
- 伸びた投稿は**1ヶ月後に言い回しを変えて再投稿**。新規フォロワーには初見です

## 6. Instagram 投稿設計

### フィード（週3投稿）

| 曜日 | 内容 | 形式 |
|---|---|---|
| 月 | ノウハウ図解 | カルーセル7〜10枚（保存を狙う） |
| 木 | 実績・プロセス | 1枚画像＋長文キャプション |
| 土 | リール | 30〜45秒のハウツー |

### カルーセルの構成（保存されるための型）

```
1枚目：タイトル（大きい文字・数字を入れる）
2枚目：なぜ必要か
3〜8枚目：手順を1枚1ステップ
9枚目：まとめ
10枚目：「保存して後で見返してください」＋プロフィール誘導
```

### デザインルール（Canvaでテンプレ化）

- 使う色は**3色まで**（メイン／サブ／アクセント）
- フォントは**2種類まで**
- 1枚目は文字を大きく。スマホの小さいプレビューで読めるか必ず確認
- **顔出しは不要**。手元の写真・パソコン画面・ノートで世界観は作れます

## 7. AIを使ったコンテンツ量産の手順

「ライター」役をAIに任せる時の実務手順。

```
STEP 1: 自分の体験を音声メモで3分喋る（スマホの音声入力でOK）
STEP 2: 文字起こしをAIに渡す
STEP 3: プロンプト例↓
```

**量産用プロンプト**
```
以下は私（40代主婦・在宅ワーク発信者）の体験談メモです。
これをもとに、Threads用の投稿を5パターン作ってください。

【条件】
- 各150〜250文字
- 冒頭2行で読者が止まる書き出しにする
- 40代主婦が使う自然な話し言葉。専門用語は使わない
- 「稼げる」「必ず」「誰でも」は使わない
- 押し売りせず、体験の共有として書く
- 5パターンはそれぞれ違う切り口（共感/意外性/数字/失敗談/問いかけ）にする

【体験談メモ】
（ここに文字起こしを貼る）
```

> **必ず自分の体験をインプットにしてください。** ゼロから生成させた投稿は、
> どれだけ整っていても読者に見抜かれます。40代主婦層はそこに特に敏感です。
> AIは「あなたの体験を整える道具」であって、「体験を作る道具」ではありません。

**STEP 4**: 出てきた5案を自分で読み、**必ず1箇所は自分の言葉に書き換える**
**STEP 5**: 数字・固有名詞が事実と合っているか確認して投稿
