# 10. 公式LINE ステップ配信 全文原稿（7通）

> **ここが「自動で月20万」の"自動"の正体です。**
> 一度書き切れば、あなたが寝ている間も、子どもの送り迎えをしている間も、
> このメッセージが順番に届き続けます。7通を書く数日間が、この事業で最も費用対効果の高い時間です。

---

## 使い方

- **【　】は自分の事実に書き換えてください。** ここを埋めないと全部が嘘になります
- **架空の体験を書かないでください。** 書けない通は、体験してから書く。それまでは6通で回して構いません
- 文字数は1通あたり400〜600字を目安に。LINEは長文だと開いた瞬間に閉じられます
- **改行を多めに。** スマホで読むので、3〜4行ごとに空行を入れます
- 絵文字は1通に2〜3個まで。多いと業者っぽくなります

## PR表記のルール

**案件へのリンクや、特定サービスへの言及を含む通には、冒頭に［PR］を入れてください。**
本原稿では4・5・6・7通目が該当します。

迷うくらいなら**全7通に入れるのが最も安全**です。1〜3通目に入れても離脱率はほとんど変わりません。
隠すメリットより、バレたときの損失の方が圧倒的に大きいです。

|---|---|---|---|---|

【苦手だったことの具体例】

そんな状態から在宅ワークを始めて、

正直に書くと、
最初の【期間】は収入ゼロでした。

「向いてなかったのかも」と

なので、このLINEでは
うまくいった話だけじゃなくて、

# 【2通目】翌日20:00｜なぜ始めたか（ストーリー）

```
こんばんは、【ニックネーム】です。

今日は、なんで在宅ワークを
始めようと思ったのかを書きます。

きっかけは【具体的な出来事】でした。

【その時の状況を3〜4行で。
　金額・時間・場所など具体的に】

そのとき思ったのが、
「このままだとまずい」じゃなくて、
「私、選べる立場じゃないな」
ということでした。

働きたくても、
子どもの都合で急に休むことになる。
それが分かってるから、応募もためらう。

選択肢がない状態が、
一番しんどかったです。

だから在宅ワークを選んだのは、
「稼ぎたい」より先に
「選べるようになりたい」でした。

たぶん、同じことを思ってる方が
このLINEを読んでくださってると思います。

次回は、40代主婦が現実的に選べる

**狙い**: 共感の最大化。ここで「この人は私と同じだ」と思ってもらえるかが全て

「【金額】円の請求書を見て、パート代では足りないと分かった」のように具体で書くと、感情は勝手に伝わります

# 【3通目】3日目20:00｜在宅ワーク3つの選択肢

```
こんばんは。

「在宅ワーク」で検索すると
情報が多すぎて疲れませんか。

私も最初、50個くらいのサイトを見て
逆に何も決められなくなりました。

なので、40代から始めるなら、
現実的には3つしかないと思っています。

──────────

①今すぐお金になるもの
　データ入力、テープ起こし、アンケートなど
　→ すぐ始められる。ただし単価は低い
　→ 月5,000〜3万円くらい

②スキルを覚えてから稼ぐもの
　ライティング、デザイン、事務代行など
　→ 3〜6ヶ月かかる
　→ 月3万〜20万円

③自分で発信して稼ぐもの
　ブログ、SNSなど
　→ 半年〜1年かかる
　→ 上限はないが、時間もかかる

──────────

私は①から入って、
今は②と③をやっています。

順番はけっこう大事で、
いきなり③から入ると
9割の人がやめます。

理由は簡単で、
半年間ずっと収入ゼロだからです。

まず①で「本当にお金が入る」を
体験してから②に行くのが、
遠回りに見えて一番早いです。

次回は、①を無料で始める方法を
具体的にお送りしますね。
```

**狙い**: 情報の整理＝価値提供。ここで「この人は分かってる」と信頼が確定します
**設計意図**: 「①→②」という順番を提示することで、**4通目（B層＝①）と6通目（A層＝②）が
自然な流れになります。** ここが7通全体の設計の要です
**禁止**: まだ売らない。あと1通だけ我慢

# 【4通目】5日目20:00｜まず無料でできること（B層案件）

```
［PR］

こんばんは。

前回お話しした「①今すぐお金になるもの」を、
無料で始める方法です。

やることは1つだけ。
求人サイトに登録することです。

ただ、ここで注意があって、
在宅ワークの求人サイトには
正直あやしいものも混ざっています。

私が実際に使って、
安全だと思ったのは次の2つです。

──────────

▼【サイト名A】
主婦向けの在宅求人に特化しています。
子育て中の事情を分かっている
クライアントが多いのが理由です。
登録は無料、【所要時間】分くらいでした。

▼【サイト名B】
国内最大級で、案件数がとにかく多い。
「未経験OK」の募集も豊富です。
私が最初の1件を取ったのはこちらでした。

──────────

両方とも登録は無料です。
お金を請求されることはありません。

もし「登録にお金がかかる」と言われたら、
それは在宅ワークではないので
すぐ離れてください。

▼ 2つの違いを詳しく比較しました
【ブログの比較記事URL】

正直に書くと、登録してすぐ

**狙い**: **初報酬の発生源。** 無料登録なので読者にリスクがなく、最も成約する通
**リンク設計**: LINE内にASPリンクを直接置かず、**ブログの比較記事へ1本だけ**。
記事内でB層2案件を回収します（SNS/LINEへの直リンクを避ける設計）
**必須**: 冒頭［PR］／「20件落ちた」の正直な数字（ここがないと業者に見えます）
**KPI**: この通のリンククリック率20%以上が目標。下回ったら文面を書き直し

もし1つも使えてなくても大丈夫です。

そのまま3週間放置しました😅

どのくらい変わったかの話をします。

今は【時間】です。

何をしたかというと、
プロンプト集の【番号】番を使って
構成だけAIに作らせて、
中身は自分で書く、という形にしました。

全部AIに書かせると、
不思議なくらい「読めない文章」になります。
なので構成だけ。ここが分かれ目でした。

──────────

もう1つ、地味に効いたのが
画像を作るツールを有料版にしたことです。

月【金額】円ですが、
1回の作業が【時間】短縮されるので、
時給換算すると余裕で元が取れました。

▼ 私が実際に使っているツールをまとめました
【ブログのツール紹介記事URL】

**注意**: ここで強く売らない。「無料でできることもある」と引くのが正解です

```
［PR］

こんばんは。

ここ数日、
「スクールって行った方がいいですか？」
という質問を何通かいただきました。

正直に書きます。

**独学でいけます。**

私も最初の【期間】は独学でした。
今もYouTubeとブログで学んでいることは
たくさんあります。

ただ、独学には向き不向きがあります。

──────────

▼ 独学が向いている人
・まとまった時間が取れる
・分からないことを自分で調べるのが苦じゃない
・半年〜1年かけてもいい
・一人でも続けられる

▼ スクールが向いている人
・子どもがいて時間が細切れ
・「何が分からないか」が分からない
・3ヶ月で形にしたい
・一人だと絶対に続かない自覚がある

──────────

私は完全に後者でした。

夜11時に調べ物をしていて、
「この時間、誰かに聞ければ5分で終わるのに」
と何度も思ったので。

あと、これは人によりますが、
お金を払うと辞められなくなる、
というのが私にはかなり効きました。

逆に、時間があって自分で調べるのが
苦じゃない方は、
独学でまったく問題ないと思います。

▼ スクールを3つ比較した記事です
（行かない選択肢についても書きました）
【ブログの比較記事URL】

無料説明会を受けたときの話を書きます。

正直、身構えて行きました。
その話をします。
```

**狙い**: A層への橋渡し。**ここで売り込むと全部壊れます**
**最重要**: 「独学でいけます」を**最初に太字で書く**こと。
ここで「独学は無理です」と書いた瞬間に売り込みになり、賢い読者ほど離れます。
**両論併記が最も売れる**という、直感に反する原則がこの通の全てです
**リンク**: 比較記事1本のみ。「行かない選択肢についても書きました」を必ず添える
**KPI**: ブロック率をこの通で必ず確認。10%超なら売り込みが強すぎます

# 8通目以降（Phase 3）｜週1配信で関係を維持する

2週間のステップが終わったら、**週1回の定期配信**に移行します。
ここが「LINEリストがストック資産になる」フェーズです。

### 配信ネタのローテーション（4週サイクル）

| 週 | テーマ | 売る? |
|---|---|---|
| 第1週 | 今週のAIニュース×主婦目線 | 売らない |
| 第2週 | 読者からの質問に答える | 軽く（案12・Q&A回収型） |
| 第3週 | 私の進捗報告（数字を正直に） | 売らない |
| 第4週 | 使ってよかったもの／キャンペーン情報 | **売る**（案11・キャンペーン便乗型） |

**売るのは月1回まで。** これを守ると、1年経ってもブロック率が低いまま維持できます。

### セグメント配信（登録数500人を超えたら）

反応で分けると、成約率が体感2倍近く変わります。

| セグメント | 判定方法 | 配信内容 |
|---|---|---|
| **行動層** | 4通目のリンクをクリックした人 | A層（スクール）を強めに。行動力があるので刺さります |
| **検討層** | 6通目は開いたがクリックなし | もう一度、独学ルートの情報を厚めに |
| **休眠層** | 30日以上未開封 | 月1回だけ。追いかけない |

# リッチメニュー設計（LINE画面下部の固定メニュー）

```
┌──────────┬──────────┬──────────┐
│ プロンプト │ 在宅ワーク │  よくある  │
│  集50を    │  求人サイト│   質問     │
│  見る      │  比較      │            │
├──────────┼──────────┼──────────┤
│ スクール   │  ブログ    │  質問する  │
│ 3社比較    │  を読む    │（個別相談）│

```

- 左上は必ず**プレゼント再ダウンロード**（「もらったやつどこ？」が最も多い問い合わせです）
- 右下の「質問する」は、**ネタの供給源**になります（案12・Q&A回収型に直結）

# 執筆チェックリスト

- [ ] 【　】が1箇所も残っていない
- [ ] 体験していないことを書いていない
- [ ] 案件に触れる通（4〜7）の冒頭に［PR］がある
- [ ] 1通につきリンクが1つだけ
- [ ] 「必ず」「誰でも」「確実に」「絶対」を使っていない
- [ ] 収益・成果を保証する表現がない
- [ ] 他社を実名で批判していない
- [ ] 1〜3通目で何も売っていない
- [ ] 6通目で「独学でいけます」と最初に書いている
- [ ] 7通目で「申し込まなくていい」と書いている
- [ ] 全リンクが実際に開けるか、自分のスマホで確認した

> **最後の項目を飛ばさないでください。** 配信設定のミスで
> 「4通目が1通目に届く」「同じ通が2回届く」は、実際によく起きます。
> **必ず自分の別アカウントで一度通してください。**

# 数字の見方

| 指標 | 目標 | 下回ったら |
|---|---|---|
| 1通目 開封率 | 80%以上 | あいさつメッセージを見直す |
| 4通目 クリック率 | 20%以上 | 4通目の文面を書き直す |
| 6通目 ブロック率 | 5%以下 | 売り込みが強すぎる。両論併記を厚くする |
