# 02. 案件リスト30選 — 40代主婦 × AI・在宅ワーク

## ⚠️ 使う前に必ず読んでください

- **報酬単価は「調査時点の目安」です。** 実額は必ず各ASPの管理画面で検索して確認してください。
  単価は月単位で変動し、案件そのものが終了・停止することもあります。
- **取扱ASPも変わります。** 「A8.netにあったはずの案件がafbに移った」は日常的に起きます。
  記載のASPで見つからない場合は、他のASPで案件名を検索してください。
- **提携前に必ずLP（広告主のページ）を自分で読んでください。** 内容を知らずに紹介すると、
  読者からの質問に答えられず信用を失います。
- ★ = このアカウントのペルソナ（40代主婦・在宅ワーク志望）との相性が特に良い案件

## 案件の絞り込み手順（重要）

30案件全部を同時に走らせてはいけません。分散すると全部が中途半端になります。

```
Phase 0-1（1〜3ヶ月目）
  → B層から3案件（#11 ママワークス / #12 クラウドワークス / #14 ココナラ）
  → D層から1案件（#24 ConoHa WING）
  = 計4案件だけに集中

Phase 2（4〜6ヶ月目）
  → A層から2〜3案件を追加（自分が無料説明会を受けたものだけ）
  → C層から2案件（自分が課金して使っているもの）
  = 計8〜9案件

Phase 3（7ヶ月目〜）
  → E層#29（証券口座）を追加。ここで単価が跳ねる
  → 数字が出ていない案件を削る
  = 稼働8案件に収束させる
```
