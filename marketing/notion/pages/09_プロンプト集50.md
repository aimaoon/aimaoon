## はじめに

パソコンが得意じゃなくても大丈夫です。
このプロンプト集は、**コピーして【　】の中を自分の状況に書き換えるだけ**で使えます。

ChatGPT・Claude・Geminiなど、どのAIでも同じように使えます。
無料版でもほとんどのプロンプトは動きます。

---

## 使う前に：これだけ覚えれば9割うまくいく「3つの足し算」

AIに雑に聞くと、雑な答えが返ってきます。次の3つを足すだけで別物になります。

| 足すもの | 例 |
|---|---|
| **① 相手は誰か** | 「40代・パソコン初心者の主婦に向けて」 |
| **② どんな形で欲しいか** | 「箇条書きで5つ」「300文字で」「表にして」 |
| **③ 何を避けたいか** | 「専門用語は使わないで」「宣伝っぽくしないで」 |

**悪い例**：「在宅ワークについて教えて」
**良い例**：「40代・PC初心者の主婦に向けて、在宅ワークの種類を箇条書きで5つ、専門用語なしで教えて」

これだけです。以降の50個は、すでにこの3つが組み込まれています。

# 【第1章】在宅ワークを探す・見極める（10個）

### 1. 自分に向いている在宅ワークを洗い出す
```
私は40代の主婦です。以下の条件で、向いている在宅ワークを5つ提案してください。
それぞれ「必要なスキル」「月収の目安」「始めるまでの期間」を表にしてください。
専門用語は使わず、初心者にも分かる言葉でお願いします。

【使える時間】1日◯時間、主に◯時〜◯時
【今できること】（例：Excel入力、電話対応、料理、経理事務 など）
【避けたいこと】（例：電話が鳴る仕事、締切が厳しい仕事 など）
【目標収入】月◯円
```

### 2. これまでの経験を「売れるスキル」に翻訳する
```
以下は私の職歴・生活経験です。
これらを「在宅ワークの仕事に使えるスキル」として言い換えてください。
「自分では当たり前だと思っているが、実は価値がある」ものを優先して10個挙げてください。

【職歴】
【家庭内でやっていること】
【得意な家事・趣味】
```

### 3. 求人が怪しくないか判定する
```
以下の在宅ワーク求人の内容を貼ります。
この求人に「注意すべき点」があれば指摘してください。
特に、初期費用の請求・高すぎる報酬・業務内容の曖昧さ・特商法表記の有無に注目してください。
判断できない点は「判断できない」と正直に書いてください。

【求人内容】
```

### 4. 求人の「実際の時給」を計算する
```
以下の在宅ワーク求人について、実際の時給を計算してください。
作業時間には、リサーチ・修正対応・連絡のやりとりも含めて見積もってください。
一般的な相場と比べて高いか安いかも教えてください。

【報酬】
【業務内容】
【納期】
```

### 5. 未経験でも応募できる仕事を絞り込む
```
在宅ワーク初心者が「実務経験なし」でも応募できる仕事の種類を10個挙げてください。
それぞれについて「最初の1件を取るまでの平均的な難易度（5段階）」も付けてください。
なるべく現実的に、厳しめに評価してください。
```

### 6. 仕事を受ける前の確認事項リストを作る
```
在宅ワークの仕事を受注する前に、クライアントに確認しておくべきことを
チェックリスト形式で作ってください。
トラブルになりやすい項目（納品後の修正回数、著作権、支払いタイミングなど）を必ず含めてください。
```

### 7. 断り方の文面を作る
```
在宅ワークの依頼を断りたいのですが、角が立たない断り方の文面を3パターン作ってください。
今後また依頼してもらえる関係を保ちたいです。丁寧すぎず、へりくだりすぎない文体でお願いします。

【断る理由】
```

### 8. 値上げ交渉の文面を作る
```
現在の単価を上げてもらう交渉文を作ってください。
「これまでの実績」と「今後どう貢献できるか」を根拠にして、
強気すぎず、卑屈にならないトーンでお願いします。300文字程度で。

【現在の単価】
【継続期間】
【これまでの実績】
【希望単価】
```

### 9. 契約書・利用規約を要約させる
```
以下の契約書（または利用規約）を、専門用語なしで要約してください。
特に「自分が不利になる可能性がある条項」を最優先で3つ挙げてください。
不明な点は「専門家に確認すべき」と明記してください。

【本文】
```

### 10. 仕事の相場を調べる
```
【仕事の種類】の在宅ワークについて、初心者・中級者・上級者それぞれの
一般的な単価相場を教えてください。
また「初心者が最初に受けるべき単価の下限」も、消耗しない基準として教えてください。
```

## AIを使うときの3つの約束

### ① 個人情報は入れない
氏名・住所・電話番号・クレジットカード情報・子どもの学校名などは入力しないでください。
契約書を要約させる場合も、固有名詞は【A社】などに置き換えてから貼りましょう。

### ② AIの答えを鵜呑みにしない
AIは、それらしい嘘を自信満々に書きます。
**特に法律・税金・医療・金額に関する内容は必ず自分で裏を取ってください。**
「調べて」と頼んでも、実際には調べずに書いていることがあります。

### ③ 仕事で使う時はクライアントの規約を確認する
「AI利用禁止」の案件があります。黙って使うと契約違反になります。
確認してから使ってください。

## 【運用メモ｜配布者向け・PDFには含めない】

### 制作手順
1. Canvaで「A4・縦」を選択、テンプレートから資料系を選ぶ
2. 表紙＋章扉8枚＋本文＋巻末で 全35〜40ページ程度
3. プロンプト部分は**コピーできるようにNotion版も併せて配布**する
   （PDFだとコピーしづらく、離脱の原因になります）
4. ファイル名：`40代主婦のためのAIプロンプト集50.pdf`

### 章と案件の対応（自然に繋がる導線）
| 章 | 繋がる案件 |

- 理由：プレゼントの中身が広告だと分かった瞬間、ステップ配信を全部読まれなくなります
- 巻末の［PR］表記は必須（配布物も広告に該当します）
