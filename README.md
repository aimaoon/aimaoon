# プール圏内検索

あらかじめ登録しておいたプール（施設）の中から、**お客様の住所を入れるだけで
「1時間以内で行ける施設」を近い順にリストアップする**アプリです。

移動手段は 車 / 電車・バス / 自転車 / 徒歩 から選べ、上限時間も 15分〜2時間で切り替えられます。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー起動（http://localhost:5173）
npm run test     # 計算ロジックのテスト
npm run build    # 型チェック + 本番ビルド
```

1. 「プール登録」タブで施設を登録する（初回はサンプルの首都圏 12 施設が入っています）
2. 「検索」タブでお客様の住所を入力して検索
3. 移動手段・上限時間・タグで絞り込み、必要なら「Google マップで経路を見る」で実際の経路を確認

登録内容・移動手段・上限時間はブラウザの localStorage に保存されるので、次回もそのまま使えます。

## 所要時間の出し方

住所は**国土地理院の住所検索 API**（無料・API キー不要）で緯度経度に変換し、
そこからの所要時間を次の式で概算します。

```
移動距離 = 直線距離 × 迂回係数
平均速度 = 最低速度 +（最高速度 - 最低速度）× 移動距離 /（移動距離 + 立ち上がり距離）
所要時間 = 固定時間 + 移動距離 / 平均速度
```

平均速度を距離に応じて変えているのは、近所は下道で遅く、遠出ほど幹線・高速・優等列車で
速くなるためです。固定時間は駐車や駅までの徒歩・待ち時間にあたります。

| 手段 | 迂回係数 | 固定時間 | 平均速度 | 1時間圏内のおおよその直線距離 |
| --- | --- | --- | --- | --- |
| 車 | 1.30 | 5分 | 20 → 70 km/h | 約 30km |
| 電車・バス | 1.25 | 14分 | 13 → 55 km/h | 約 20km |
| 自転車 | 1.20 | 3分 | 14 km/h | 約 13km |
| 徒歩 | 1.15 | 2分 | 5 km/h | 約 4km |

**渋滞や実際のダイヤは見ていない概算**です。境目の施設は Google マップのリンクから
実際の経路時間を確認してください。係数は `src/lib/travelTime.ts` の `MODE_PROFILES` に
まとまっているので、地域の実感に合わせて調整できます。

### Google Maps などの実測に差し替える

所要時間の取得は `TravelTimeProvider` インターフェース越しに呼んでいるので、
実測値を返す実装を用意して `searchPools` に渡せば、画面はそのままで切り替わります。

```ts
const googleProvider: TravelTimeProvider = {
  id: 'google-distance-matrix',
  label: 'Google Maps 実測',
  async estimateMany(from, targets, mode) {
    // Distance Matrix API を叩いて TravelEstimate[] を返す（source: 'api'）
  },
}

await searchPools({ pools, origin, mode, limitMinutes, provider: googleProvider })
```

API キーはブラウザに置くと露出するため、実運用では自前のサーバー経由で呼んでください。

## 施設の登録

「プール登録」タブでは、1 件ずつのフォーム登録と JSON での一括登録ができます。

- 住所を入れて「住所から座標を取得」を押すと緯度経度が入ります
- 住所検索が使えない環境では、緯度経度を直接入力できます（検索欄も `35.6812, 139.7671` の形式を受け付けます）
- 「JSON をコピー」で登録内容を書き出し、別の端末で貼り付けて復元できます

一括登録の形式（`lat` / `lng` は `location: { lat, lng }` でも可）:

```json
[
  {
    "name": "○○市民プール",
    "address": "東京都○○区○○1-2-3",
    "lat": 35.6812,
    "lng": 139.7671,
    "tags": ["25m", "屋内", "温水"],
    "note": "9:00-21:00 / 大人 500円",
    "url": "https://example.com",
    "phone": "03-0000-0000"
  }
]
```

`name` と緯度経度が揃っていない行は取り込み時に飛ばし、理由を画面に表示します。
同じ `id` の施設は上書きされます。

サンプルデータ（`src/data/samplePools.ts`）の座標は施設周辺の概略値です。実運用では
自社の施設リストに置き換えてください。

## 構成

```
src/
├── types.ts                    施設・出発地・所要時間の型
├── lib/
│   ├── geo.ts                  直線距離（ハーバサイン）と座標の妥当性チェック
│   ├── travelTime.ts           移動手段ごとの所要時間モデルと Provider インターフェース
│   ├── geocode.ts              国土地理院 API での住所 → 緯度経度
│   ├── search.ts               所要時間の算出・並べ替え・絞り込み
│   ├── pools.ts                施設の JSON 入出力とタグ処理
│   ├── format.ts               時間・距離の表記と色分け
│   ├── maps.ts                 Google マップ経路リンク
│   └── *.test.ts               上記のテスト（54 件）
├── data/samplePools.ts         サンプル登録
├── components/
│   ├── AddressForm.tsx         住所入力と候補選択
│   ├── SearchControls.tsx      移動手段・上限時間・絞り込み
│   ├── ResultList.tsx          結果一覧（圏外は折りたたみ）
│   ├── PoolManager.tsx         施設一覧と JSON 一括登録
│   └── PoolForm.tsx            施設の登録・編集フォーム
└── App.tsx                     画面全体の組み立て
```

計算部分は `src/lib` に純粋な TypeScript として切り出してあり、UI なしでテストできます。
