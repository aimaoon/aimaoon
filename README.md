# メール対応ツリー管理

お客様のメールアドレスごとにやりとりをツリー化し、**「最後のメールが自社の共通ドメインで終わっているか」**
＝ 同じ会社の誰かがお客様にきちんと返せているか、を一目で分かるようにするアプリです。

担当者個人ではなく **ドメイン単位** で判定するのがポイントです。担当が田中さんから佐藤さんに
変わっていても、どちらも自社ドメインから返信していれば「対応済み」になります。

## 判定ルール

スレッド（1 つのやりとり）の中で **いちばん新しいメールの送信者** を見て判定します。

| 状態 | 条件 | 意味 |
| --- | --- | --- |
| 🟢 対応済み | 最終メールの送信元が自社ドメイン | 自社の誰かが返信済み。ボールは相手側 |
| 🔴 要対応 | 最終メールの送信元が社外 | まだ誰も返していない。ボールは自社側 |

要対応の場合は「いつからボールが自社にあるか」（= 自社の最終返信より後にきた最初の社外メール）
を基準に、放置時間で色が変わります。

- 24 時間未満: 黄
- 24〜72 時間: 橙
- 72 時間以上: 赤

自社ドメインは**サブドメインも自社として扱います**。`sample-sol.co.jp` を登録しておけば
`suzuki@support.sample-sol.co.jp` からの返信も「対応済み」になります。

## ツリーの構造

```
@mirai-shoji.co.jp              ← 社外ドメイン（≒ お客様の会社）
└── 山田 太郎                    ← 社外アドレス
    ├── 【御見積】基幹システム…   ← スレッド  🔴 要対応 3日前から
    └── 定例ミーティングの日程調整  ← スレッド  🟢 対応済み（最終対応 佐藤 美咲）
```

- 自社アドレスはツリーの見出しには出しません。「どのお客様に対応できていないか」を見るための構造です。
- 社内メールだけのスレッドは表示されません。
- 要対応を含むドメイン・アドレスが上に、放置が長い順に並びます。
- 1 つのスレッドは「最初にメールを送ってきた社外の人」にひもづきます。Cc など他の社外参加者は
  スレッド詳細の「他の社外参加者」に表示されます。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー起動（http://localhost:5173）
npm run test     # 判定ロジックのテスト
npm run build    # 型チェック + 本番ビルド
```

画面上部の「自社の共通ドメイン」で、自社として扱うドメインを追加・削除できます。
設定は localStorage に保存されるので、次回アクセス時も残ります。

## 現在の実装範囲

メールデータは `src/data/sampleMessages.ts` のサンプルです（起動時刻を基準にした相対日時なので、
経過時間の表示は常に自然になります）。IMAP や Gmail API からの取り込みはまだ実装していません。

実データにつなぐ場合は `src/types.ts` の `Message` 型に合わせて配列を用意し、
`src/App.tsx` で `SAMPLE_MESSAGES` の代わりに渡せば、ツリーも判定もそのまま動きます。

```ts
interface Message {
  id: string
  threadId: string      // 同じスレッドのメールは同じ ID にする
  subject: string
  from: EmailAddress    // { name?: string; address: string }
  to: EmailAddress[]
  cc?: EmailAddress[]
  sentAt: string        // ISO 8601
  body: string
}
```

## 構成

```
src/
├── types.ts                  メール／アドレスの型
├── lib/
│   ├── address.ts            ドメイン抽出と自社判定（サブドメイン対応）
│   ├── tree.ts               ツリー構築と対応状況の判定
│   ├── filter.ts             検索・要対応での絞り込み
│   ├── format.ts             経過時間の表記と深刻度
│   └── *.test.ts             上記のテスト
├── data/sampleMessages.ts    デモ用データ
├── components/
│   ├── TreeView.tsx          3 階層ツリー
│   ├── ThreadDetail.tsx      スレッドのやりとり表示
│   ├── DomainSettings.tsx    自社ドメイン設定
│   └── StatusBadge.tsx       状態バッジ
└── App.tsx                   画面全体の組み立て
```

判定ロジックは `src/lib` に純粋な TypeScript として切り出してあり、UI なしでテストできます。
