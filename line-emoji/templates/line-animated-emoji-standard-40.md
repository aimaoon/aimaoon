# 標準40個テンプレート（LINEアニメーション絵文字）

本プロジェクトが唯一の標準構成として使用するファイル。配分は
**キャラクター32個＋キャラクターなしの記号8個**。

40個すべてにキャラクターを出すと商品一覧が重く単調に見えるため、33〜40は
文章の後ろへ付けやすい記号にする。

## 配分

| 区分 | 番号 | 個数 | キャラクター |
|---|---|---|---|
| 会話の基本 | 01–12 | 12 | あり |
| 明るい感情・反応 | 13–24 | 12 | あり |
| 困った感情 | 25–32 | 8 | あり |
| 使いやすい文字・記号・エフェクト | 33–40 | 8 | なし |

## 40個のアニメーション・バリエーション表

意味と主動作が違うだけでは合格にしない。次の6項目の**組み合わせ**を
全40個で一意にすることを条件とする。

| 項目 | 取りうる値 |
|---|---|
| `motion_family` | 全身 / 片腕 / 両手 / 頭 / 足 / 小物 / エフェクト |
| `spatial_path` | 縦 / 横 / 斜め / 円弧 / 円 / 放物線 / 奥行き / 交差 / 画面外 |
| `tempo_class` | slow / medium / fast |
| `beat_pattern` | 単発 / 大小2拍 / 遅延2拍 / 2連打 / 3連打 / 4交互 / 連続 / 呼吸 / 3段階 |
| `peak_hold` | 最大動作を保持するミリ秒 |
| `loop_return_type` | 通常復帰 / 反動 / 退出再登場 / 戻らず保持 |

一意性は `reports/uniqueness-matrix.csv` で検証し、衝突は
`reports/collision-report.md` に記録する。

## 記号8個の必須動作

単純な点滅・拡大・傾斜は不可。構成部品が別方向から飛来する／組み上がる／
分離する／落下する／交差することを必須とする。

- **OK!** — O・K・！が別方向から弧を描いて集まり、衝突して完成する
- **ハート** — 小箱のふたが開き、3つのハートが別々の放物線で飛び出す
- **汗** — 3粒が異なる始点から噴き出し、それぞれ別の放物線で落下する
- **！？** — ！が上から落下し、？が横から飛来して中央で衝突する
- **？** — 曲線本体と点を別々に動かして組み立て、点だけを大きく跳ねさせる
- **キラキラ** — 3つの星が別方向から飛来して中央を交差し、別方向へ広がる
- **炎** — 火種が跳ね、左右の炎が開き、中央炎が立ち上がる3段階にする
- **zzz** — 各文字が前の文字を押し出しながら現れ、3本の別軌道で斜め上へ進む
