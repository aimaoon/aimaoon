# デザインブリーフ — お眼鏡の女子 / Megane-no-Ko

**確定日:** 2026-08-27 ／ **基準画像:** `character-master.png`

## 1. 商品コンセプト

> **厚手のビニールシールから抜いたような白フチのボディに、顔いっぱいの丸メガネが乗った女の子。**

動物名にも「かわいい」にも頼らず一文で言い切れること（6-C 条件1）を満たすため、
「素材（プニプニのダイカットシール）」と「主役造形（顔幅と同じ直径の丸メガネ）」の
2点だけで説明できる形にした。

- **想定購入者**: メガネをかけている10〜30代の女性
- **利用場面**: 日常のLINE会話。挨拶・返事・お礼・お願い・困った報告・文末の記号
- **文字**: キャラクター32個は文字なし（ユーザー指定）。記号8個のみテンプレートが
  定める `OK!` `!?` `?` `zzz` を使用

## 2. ユーザー指定への対応

| 指定 | 実装 |
|---|---|
| メガネのおしゃれ女子 | 顔幅いっぱいの丸メガネを主役造形に据え、白いスナップピンで「おしゃれ」を補強 |
| 輪郭線は細く | 本体輪郭 **1.7px** 固定（180px基準）。メガネのフレームだけ3.0pxで、視線が最初にメガネへ行く |
| 配色は2色まで | 有彩色は **すみれ墨 `#3E3550`** と **アプリコットミルク `#F7CDBE`** の2色のみ。白と透明は地として扱う |
| 表情はゆるく | 目は半径3.7pxの点目が基準。眉・口ともに線1本〜2本の最小構成。陰影・グラデーションなし |
| プニプニシール | 2.6pxの白いダイカットフチ＋髪の三日月グロス1つ。テクスチャは持たせず、フチの太さと角の丸みだけで素材を出す |

## 3. 視覚的フック（4つ）

40個へ展開しても大半で認識できることを条件に、装飾ではなく主要造形へ組み込んだ。

1. **顔幅いっぱいの丸メガネ** — 左右レンズの外径の合計が顔の幅とちょうど一致する。
   32pxでも「暗い髪の塊のなかに明るい円が2つ」として残る、最も強いフック
2. **ダイカットの白フチ（2.6px）** — どんな背景に置いてもシールとして浮く。
   エフェクトと記号8個にも同じフチを付け、シリーズの共通言語にしている
3. **非対称ボブ** — キャラクター左のジョーの毛先だけが外へ跳ねる。シルエットで効く
4. **白いスナップピン2本** — 前髪のキャラクター右側。ボブを「手入れされた髪型」に見せる

## 4. 固定するもの / 変化させるもの

**固定（`style-lock.json` の `forbidden_changes`）**
頭身、顔の基本構造、メガネの形と位置、2色＋白の配色、線幅、
白フチ、跳ね毛、ヘアピン、レイヤー順、陰影を持たないという原則。

**変化させる**
目と口（11種×10種）、眉4種、頭の傾きと上下、上半身の前傾と反り、腰の沈み、
両腕の到達位置、脚の接地、肩の上下、スカートの開き、
そして各項目に1つだけ決めた主役エフェクト。

## 5. 「凝ったデザイン」として採ったもの／採らなかったもの

**採った**: 独自シルエット（顔幅と一致する丸メガネ＋非対称ボブ）、
小サイズで判別できる2色配色、素材と結びついた白フチ、
キャラクターと同じ線・塗り・フチで描くシリーズ専用エフェクト。

**採らなかった**: 毛の描き込み、細かい服の柄、小さなアクセサリーの追加、
縮小すると消えるテクスチャ、極細線。いずれも32pxで消えるため、
デザイン性として数えない方針に従った。

小サイズで潰れる箇所は、細部を足さずに**メガネを大きくする／エフェクトを大きくする／
線を整理する**方向で解決している。

## 6. 独自性・商品力ゲート（6-C）の自己判定

| # | 観点 | 判定 | 根拠 |
|---|---|---|---|
| 1 | 動物名や「かわいい」を使わず一文で説明できるか | 可 | 第1節の一文 |
| 2 | 量産型に見えないか | 可 | 丸顔＋点目は共通だが、顔幅と一致するメガネと白フチが上書きしている |
| 3 | シルエットだけで区別できるか | 可 | 非対称ボブ＋跳ね毛＋メガネの厚みが輪郭に出る |
| 4 | フックが主要造形に入っているか | 可 | 4つのうち3つが造形そのもの、1つが素材表現 |
| 5 | 40個並べて統一感と変化があるか | **一部未達** | 統一感は十分。変化は構図が立ち姿に偏っている（`reports/composition-balance.md`） |
| 6 | 小さなサムネイルで他商品と同化しないか | 可 | メガネと白フチが32pxで残る |
| 7 | 奇抜すぎて日常で使いにくくないか | 可 | 造形は素直で、用途は日常会話の40場面に限定している |

観点5が未達のため、**構図の第2パスを推奨**として
`reports/composition-balance.md` に具体案を残した。

## 7. 採点結果（`reports/design-quality-audit.csv`）

5項目×20点＝100点満点。3項目は書き出し後のフレームからの実測値、
2項目（`concept_strength` / `material_and_depth`）は作者判断であることを
CSVの `basis` 列に明記している。

- 平均 **84.1** / 最高 95.0 / 最低 75.3
- 合格（80点以上かつ全項目12点以上）: **27件**
- 要改善（全項目12点以上だが合計80点未満）: **13件**

要改善13件はすべて `silhouette_originality` と `small_size_product_appeal` の
不足による。両指標はセット内の32px最近傍距離から算出する**相対指標**のため、
個別の項目を強くしても他が下がる。底上げには構図そのものを散らす必要があり、
第2パスの対象とした。
