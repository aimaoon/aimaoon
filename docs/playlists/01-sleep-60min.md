## 2. YouTube オーディオライブラリから取る場合

**注意: オーディオライブラリには「曲ごとの公開ダウンロードURL」が存在しない。** 必ず自分のチャンネルにログインした状態で YouTube Studio 経由で落とす。外部サイトが配っている「オーディオライブラリのMP3直リンク」は非公式なので使わないこと。

**手順**
1. https://studio.youtube.com を開く → 左メニュー **「オーディオ ライブラリ」**
2. フィルタを次の順で設定
   - ジャンル: **アンビエント**
   - ムード: **穏やか（Calm）**
   - 再生時間: **5分以上**（長いほど編集が楽）
   - 帰属表示: **「帰属表示は不要」でフィルタ**（説明欄のクレジット管理が消える）
3. 各行の ⬇ でMP3を取得

## 3. 編集仕様（ここが再生時間を決める）

| 項目 | 値 | 理由 |
|------|-----|------|
| クロスフェード | **8〜15秒** | 曲間に無音を作らない。無音＝覚醒トリガー |
| 冒頭フェードイン | 5秒 | 頭の「ボッ」を消す |
| 末尾フェードアウト | **最後の3分**をかけて -∞ | 終わりに気づかせない |
| ラウドネス | **-18 LUFS**（-16〜-20の範囲） | 通常音楽（-14）より下げる。夜に爆音は致命的 |
| True Peak | -3 dBTP 以下 | クリップ音は一発で起こす |
| ハイシェルフ | 8kHz以上 -3〜-6dB | シャリつきを抑える |
| ローカット | 30Hz以下 | スマホスピーカーで無駄に歪む帯域を削る |
| 禁止 | 打楽器のアタック / リバースシンバル / 急な転調 | 全部「起こす」音 |

**確認方法**: 完成尺を等倍で1回通しで聴き、波形を見る。**波形が右肩下がりの三角形**になっていれば設計通り。

## 4. アップロード設定（睡眠系の勝ち筋）

- **タイトル例**: `【睡眠用BGM】60分で眠りに落ちる癒しの音楽｜広告なし・黒画面`
- **サムネ**: 暗い。輝度を落とす。文字は最小限。夜スマホで見て眩しくないこと
- **映像**: 黒画面 or 極低速ループ。フレーム内で明るさが変動しないもの
- **広告**: **途中広告オフ必須**（睡眠系で途中広告を入れると即離脱＋低評価）
- **チャプター**: 睡眠用には**付けない**（シークさせない＝視聴維持率が伸びる）
- **説明欄**: 音源クレジット（Pixabayは不要だが書いておくと申立て時の防御になる）＋ シリーズ導線

### 収益化に関する重要な注意

フリー音源をそのまま並べただけの動画は、YouTube の**「再利用されたコンテンツ」**に該当して収益化審査に落ちる例が多い。落ちないために最低限:

1. 曲順・ミックス・EQ・フェードを**自分で編集**する（本ドキュメントの §3 がその実体）
2. 映像を**自作**する（他人のフリー素材の垂れ流しにしない）
3. シリーズとしての一貫した編集方針を持つ

また Pixabay / オーディオライブラリの曲は**誰でも使える＝他チャンネルと被る**。Content ID の誤検知申し立てが来ることもあるので、ダウンロードした日付とページURLの記録を残しておくこと（この表がその記録を兼ねる）。
