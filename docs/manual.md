# Stage Note 使い方ガイド

はじめて開く人が、そのまま順番になぞれば使えるようにまとめたものです。
画面写真つきの読みやすい版もあります → https://claude.ai/code/artifact/583958f6-9969-4ddf-b500-7d27f67ce6e0

---

## 1. これは何のアプリ？

出るコンテストを 1 件ずつ登録して、その大会にひもづく「やること」と「思い出したいこと」を
全部そこにぶら下げておく、紙のノートの代わりです。

- **入金したか** — エントリー費と入金期限。まだなら締切前に教えてくれます。
- **音源を出したか** — 提出期限、提出方法、そして「当日持参」かどうか。
- **会場はどこか** — 住所からワンタップで Google マップを開けます。
- **ファイナルはどうなったか** — 予選とファイナルを、1 つの大会としてまとめて持てます。
- **誰がジャッジか** — ジャッジ名で過去の大会を横断して探せます。
- **終わったあと何を思ったか** — 結果・よかったこと・課題・次にやること。

入力した内容は**使っている端末の中にだけ**保存されます。どこかのサーバーに送られることはありません。
そのぶん機種変更やブラウザのデータ削除で消えてしまうので、[バックアップ](#15-バックアップを取る)だけは覚えて帰ってください。

## 2. まず、ホーム画面に置く

ブラウザのタブのままでも使えますが、ホーム画面に置くとアドレスバーが消えて普通のアプリと同じ見た目になり、
通知も受け取れるようになります。

**iPhone / iPad**

1. **Safari** でアプリの URL を開く（Chrome など他のブラウザからは追加できません）
2. 画面下まんなかの共有ボタン（□に↑）を押す
3. 「ホーム画面に追加」を選ぶ（メニューを下にスクロールすると出てきます）
4. 右上の「追加」を押す

**Android**

1. Chrome でアプリの URL を開く
2. 右上の「⋮」を押す
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

> iPhone では、**ホーム画面に追加したアイコンから開いたときだけ**通知を許可できます。
> Safari のタブのままだと「この端末で受け取る」を押しても登録できません。

## 3. 最初の画面で選ぶ

はじめて開くと案内が出ます。ボタンは 2 つ。

- **最初の大会を登録する** — すぐ入力画面に進みます。
- **サンプルで中身を見る** — 架空の大会が数件入った状態で開きます。

サンプルはあとから消せます（設定タブ → データの整理 → すべて削除）。

## 4. 大会を登録する

画面右下のピンクの丸い **＋** が「大会を追加する」です。イベントタブとカレンダータブに出ています。

| カード | 入れるもの |
| --- | --- |
| 基本 | 大会名／部門・カテゴリ／開催日／集合・開始／終了予定 |
| 会場 | 会場名と住所（住所を入れると地図が開けます） |
| ファイナル | 決勝がある大会だけ。あとから足せます |
| エントリー費 | 金額・入金期限・支払い方法（入金期限を入れると通知の対象に） |
| 音源 | 曲名・提出期限・提出方法 |

必須は**大会名だけ**です。最後に一番下の「この内容で追加」（または右上の「保存」）を押します。

> まずは **大会名・開催日・入金期限・音源の提出期限** の 4 つだけ入れておけば、
> 締切を落とさないという目的はほぼ達成できます。

## 5. 画面の見かた

画面のいちばん下に 4 つのタブがあります。

- **イベント**（トロフィー）— 登録した大会の一覧。ふだんはここ。
- **カレンダー** — 開催日と締切を月のカレンダーで見る。
- **通知**（ベル）— これから鳴る予定の一覧と、通知の設定。
- **設定** — バックアップ・見た目・サンプルの読み込みなど。

トロフィーの右上に付くピンクの数字は「期限が近い・過ぎている用事の数」です。

一覧のいちばん上には、締切が近い・過ぎているもの（赤い線の枠）と、
振り返りが空のまま終わった大会への案内が出ます。どちらも押すとその大会に飛びます。

並び替えは「これから／要対応／終わった／すべて」の 4 つ。ふだんは「これから」のままで大丈夫です。

## 6. 入金を管理する

大会を開いて「入金」のところ。上のボタンで今の状態を選ぶだけです。

- **未入金** — 入金期限が近づくと通知と警告が出ます。
- **一部入金** — いくら払ったかを入れると、残りを計算して出します。
- **入金済み** — 押した日が自動で「入金日」に入ります（あとから直せます）。
- **費用なし** — 無料の大会、ゲストショーなど。警告の対象から外れます。

下の空欄は振込先や支払い方法のメモです。
払い終わったら、カードの一番下の「入金済みにする」を 1 回押すだけでも完了します。

## 7. 音源と「当日持参」

- **未準備** — まだ曲を用意していない。
- **用意済み** — データはできたが、まだ提出していない。
- **提出済み** — 主催に送り終わった。

事前提出がなく当日持ち込む大会は、状態ボタンの下の **当日持参** にチェックを入れてください。
その大会は音源の準備は済んだ扱いになり、**提出期限の通知も出なくなります**。
一覧のカードにも「当日持参」と表示されます。チェックを外せば通常の管理に戻ります。

## 8. 会場を地図で開く

登録のときに**住所**を入れておくと、詳細に地図のボタンが出ます。

- **Google マップで開く** — その住所を表示します。
- **経路** — いまいる場所からの行き方を出します。

住所は正確でなくても構いません。「渋谷 WOMB」のような会場名だけでもたいてい見つかります。
下の空欄は会場のメモ（出演者入口、楽屋の場所など）です。

## 9. ファイナルを管理する

予選を勝ち抜いた先に決勝がある大会は、**予選と決勝を別々の大会として登録せず**、
1 つの大会の中で管理します。

- 日程がまだ出ていない → **ファイナル権を獲得した** を押す。権利だけ先に記録できます。
- 日程がわかっている → **日程を登録する** から開催日・集合時刻・会場を入れる。
  会場を空にすると予選と同じ会場として扱われます。

結果は「結果待ち／ファイナル権獲得／敗退」の 3 つ。
**敗退**にすると、ファイナルの通知とカレンダー書き出しから外れます。

予選の日が過ぎてファイナルの日程が残っている大会は、一覧でファイナルの日付を使って並びます。

## 10. ジャッジで絞り込む

大会の詳細の「ジャッジ」に、名前とジャンルを入れて「追加」。
下の空欄にはその人について気づいたことを書けます（「ミュージカリティ重視」など）。

イベントタブの検索窓の下にある **ジャッジ** ボタンを押すと、登録済みの名前が件数つきで並びます。
名前を押すと、そのジャッジが入っていた大会だけが一覧に残ります。
隣の **ファイナル権獲得** と組み合わせることもできます。解除は「条件をクリア」から。

## 11. 振り返りを残す

詳細の下のほうにある「振り返り」に、星（5 段階）・結果・3 つの欄を書きます。

- **よかったこと** — 通用した動き、うまくいった準備
- **課題** — 崩れたところ、足りなかった準備
- **次にやること** — 次の大会までに練習すること

終わった大会で振り返りが空だと、一覧の上に案内が出ます。
開催前に「次にやること」へ目標を書いておく使い方もできます。

## 12. 探す・カレンダーで見る

- **大会を探す** — イベントタブの検索窓。大会名・会場・ジャッジ・メモのどれでも引っかかります。
- **予定を探す** — カレンダータブの検索窓。予定そのもの（開催日・ファイナル・入金期限・音源期限）を探します。

カレンダーの点の色：

| 色 | 意味 |
| --- | --- |
| ピンク | 開催日 |
| シアン（水色） | ファイナル |
| 琥珀（黄） | 入金期限 |
| 白 | 音源期限 |

日付を押すと、その日の予定がカレンダーの下に出ます。「今日」を押すと今月に戻ります。

## 13. 通知を受け取る

通知には 3 通りあります。ぜんぶ使う必要はありません。

**1. アプリを閉じていても届く（プッシュ通知）**

通知タブの一番上に「この端末で受け取る」があれば使えます。
押して、スマホが出す「通知を許可しますか？」に許可と答えてください。
登録できると「この端末で受け取る設定になっています」と表示され、
大会を足したり期限を変えたりするたびに自動で送り直されます。
やめるときは「この端末での受け取りをやめる」。

iPhone では、ホーム画面に追加したアイコンから開いたときだけ許可できます。

**2. 開いている間だけ届く**

「通知サーバーが未設定のため…」と出ているときはこの形です。
「開いている間の通知を許可する」を押すと、アプリを開いているあいだだけ
24 時間以内の予定を知らせます。閉じていると鳴りません。

**3. スマホの標準カレンダーに入れる（いちばん確実）**

大会の詳細の「カレンダーに追加（.ics）」、または通知タブの「すべての予定を書き出す（.ics）」で
ファイルができます。それをタップすると、iPhone のカレンダーや Google カレンダーに
予定とアラームごと取り込まれます。別の端末でも鳴ります。

**鳴らすタイミングを変える**

大会の詳細の「リマインダー」に、最初から 1 週間前 / 前日 / 当日の朝 の 3 つが入っています。

- チェックを外す → その通知だけ鳴らなくなる
- ✕ → 削除
- 「◯日前の ◯時」を決めて「追加」 → 増やす（当日は 0 日前）

入金を「入金済み」にしたり、音源に「当日持参」を入れたりすると、その通知は自動で出なくなります。

## 14. 見た目を変える

設定タブの「表示」で切り替えます。

- **端末に合わせる** — スマホ本体のダークモード設定に従います（ふだんはこれで大丈夫）
- **ダーク** — 黒地。暗い会場や夜のリハーサルで。
- **ライト** — 白地。昼の稽古場や屋外で。

中身はまったく同じです。

## 15. バックアップを取る

**この章がいちばん大事です。** データはこの端末の中にだけあります。
機種変更、ブラウザのデータ削除、アプリの削除で、まとめて消えます。

**控えを取る**

設定タブ → バックアップ → **バックアップを書き出す**。
`stage-note-20260819.json` のようなファイルができるので、
メールで自分に送る、iCloud Drive や Google ドライブに置くなど、**端末の外**に保存してください。

しばらく取っていないと「最後に控えを取ってから ◯ 日経っています」と出ます。それが出たら取る、で十分です。

**元に戻す**

「バックアップを読み込む」を押す**前に**、戻し方を選びます。

- **いまの内容に足す** — いまあるものは消さずに混ぜます。同じ大会は更新が新しいほうを残します。
  別の端末の控えを取り込むときはこちら。
- **すべて置き換える** — いまの内容をぜんぶ捨ててファイルの中身にします。機種変更のときはこちら。

> 「すべて置き換える」で古いファイルを読み込むと、いまのデータは戻せません。
> 迷ったら先に「バックアップを書き出す」で今の状態を控えてから読み込んでください。

## 16. 困ったとき

**入力したのに保存ボタンが押せません**
大会名が空だと保存できません。ほかの欄はすべて空でも構いません。

**通知が来ません**
① 通知タブで「この端末で受け取る設定になっています」と出ていますか。
② iPhone なら、ホーム画面に追加したアイコンから開いていますか。
③ スマホ本体の「設定 → 通知」でオフになっていませんか。
④ 集中モード（おやすみモード）が入っていませんか。
不安なら .ics でスマホの標準カレンダーに入れておくのがいちばん確実です。

**音源を事前提出しない大会なのに、未提出の警告が消えません**
音源の「当日持参」にチェックを入れてください。

**終わった大会が一覧から消えました**
「これから」の表示から外れただけです。「終わった」か「すべて」を押すと出てきます。

**機種変更します。データはどうすれば？**
古い端末で「バックアップを書き出す」→ ファイルを新しい端末に移す →
新しい端末で「すべて置き換える」を選んで「バックアップを読み込む」。

**間違えて大会を消してしまいました**
アプリの中に「元に戻す」はありません。バックアップがあれば「いまの内容に足す」で戻せます。

**サンプルのデータを消したい**
設定タブ → データの整理 → すべて削除。自分で入れたものも一緒に消えます。

**入れた内容は誰かに見られますか？**
いいえ。データは端末の中にだけ保存されます。通知を有効にしたときだけ、
通知を出すのに必要な最小限（予定の時刻と、通知に出す短い文）がサーバーに預けられます。
エントリー費やジャッジのメモは送られません。詳しくは設定タブの「プライバシーポリシー」を。

**パソコンでも使えますか？**
ブラウザで開けば使えますが、データは端末ごとに別々です。
同じ内容にしたいときはバックアップの書き出しと読み込み（いまの内容に足す）で移してください。

## 17. ことばの意味

| ことば | 意味 |
| --- | --- |
| ホーム画面に追加 | ウェブサイトをスマホのホーム画面にアプリのアイコンとして置くこと。アドレスバーが消え、通知も使えるようになります。 |
| プッシュ通知 | アプリを開いていなくても届く通知。LINE のメッセージが届くときと同じしくみです。 |
| .ics（アイシーエス） | 予定を書いたファイルの形式。タップするとカレンダーに予定とアラームごと取り込めます。 |
| バックアップ | データの控え。`.json` という 1 つのファイルとして書き出されます。 |
| 要対応 | 入金や音源の締切が近い、または過ぎているもの。トロフィーに付く数字と同じ意味です。 |
| ファイナル権 | 予選を勝ち抜いて決勝に出られる資格。日程が発表される前でも先に記録しておけます。 |
